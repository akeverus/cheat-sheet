# Java Strings (fixture для тестов)

Этот файл создан специально для интеграционных тестов: даёт топик
`programming/java-strings` с тремя вопросами, для каждого из которых
существует JSON-сид с 4 вариантами ответа. Нужно для тестов которые
ожидают что на главной показывается полноценный MCQ (`focusState=question`).

## Q1. Почему `String` в Java immutable?

Из-за thread-safety, кэширования (string pool) и безопасности (нельзя
поменять значение, переданное в `HashMap` key). Любая «модификация»
возвращает новый объект.

## Q2. Чем `==` отличается от `.equals()` для строк?

`==` сравнивает ссылки, `.equals()` — значения. Для строковых литералов
из пула `==` может казаться рабочим — это совпадение, а не контракт.

## Q3. Как развернуть строку в Java?

Самый идиоматичный путь — `new StringBuilder(s).reverse().toString()`:
O(n) по времени, корректно работает со surrogate pairs.

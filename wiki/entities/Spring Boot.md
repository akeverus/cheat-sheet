# Spring Boot

Основной фреймворк приложения. Spring Boot 3.x с Java 17.

## Использование в проекте

- Web: Spring MVC + WebFlux (для AI-клиентов)
- Security: Spring Security с токен-аутентификацией для admin
- Data: Spring JDBC (не JPA)
- Actuator: мониторинг
- Validation: Bean Validation

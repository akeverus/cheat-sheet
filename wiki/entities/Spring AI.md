# Spring AI

Интеграция с LLM через Spring AI OpenAI starter.

## Использование

- `ConfigurableAiClient` — конфигурируемый провайдер
- Поддержка OpenAI API-совместимых эндпоинтов (GPT, DeepSeek)
- Настройка через `AiClientConfig`

## Связи

- Часть [[AI Pipeline]]
- Конфигурируется через `app.aiProvider`

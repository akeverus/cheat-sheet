# Prompts Architecture

Каталог `prompts/` хранит шаблоны промптов для ручной работы с LLM при подготовке к интервью.

## Роль в проекте

- `prompts/` — внешний контур для работы с ChatGPT/LLM в ручном режиме.
- `cheatsheets/` — база знаний и источник тем.
- `modules/quiz-app/src/main/java/com/cheatsheet/quiz/service/ai/AiPrompts.java` — runtime-промпты самого приложения.

Важно: `prompts/` не подмешивается автоматически в runtime приложения и живет как отдельный архитектурный слой.

## Структура

- `markdown/` — основная версия промптов с форматированием.
- `text/` — plain-text копии для систем, где markdown нежелателен.
- `index.yaml` — реестр всех промптов и их назначений.
- `PROMPTS_RULES.md` — стандарты именования и поддержки.

## Инварианты

- Каждый файл из `markdown/` и `text/` обязан иметь запись в `index.yaml`.
- Для каждой пары `variant` (`short`, `long`, `screen`, `combine`) markdown-вариант считается каноническим.
- Изменение промпта без обновления `index.yaml` считается нарушением архитектуры.

Обратная связь

Единый лист всех feedback-поверхностей в языке Instrument. Каждый образец помечен продовым аналогом и ARIA-контрактом (role / aria-live). Цель — Фаза B: собрать распределённые по экранам состояния в один регрессионный референс.

Inline-алерты

Ассертивные сообщения в потоке страницы. Прод-фрагмент fragments/inline-alert.html = role="alert" + aria-live="assertive"; наполняется из app.js. База base.css:1275 — error-стиль; вариант .success — единственный явный. Info/warn ниже — расширение языка (в проде пока не инстанцируются).

Toast / всплывающий статус

Кратковременное подтверждение (копирование, сохранение). В текущем проде toast не инстанцируется — это кандидат языка на будущее; ARIA-контракт: role="status" + aria-live="polite", авто-дисмисс не крадёт фокус.

Скопировано в буфер

Инверсная пилюля на --ink с --shadow-lift. Не срочно → polite.

Контракт объявлений (aria-live)

Как каждый образец выше объявляется вспомогательными технологиями.

Assertive — role="alert" / aria-live="assertive"

Прерывает чтеца немедленно. Только для ошибок и срочного: inline-alert (ошибка загрузки, истёкший CSRF).

Polite — role="status" / aria-live="polite"

Ждёт паузы. Вердикт ответа, toast, спиннер, счётчик результатов поиска, «Настройки сохранены».

Busy — aria-busy="true"

Регион в процессе обновления; скелет/спиннер помечены, декоративная часть aria-hidden.

Native — Constraint Validation

Валидация формы: браузер сам объявляет и фокусирует невалидное поле, кастомный live-регион не нужен.

# DESIGN — «Instrument» (гринфилд визуальный язык quiz-app)

> Единый источник правды для макетов в `design/mockups/`. Токены — в `tokens.css`.
> Это НЕ эволюция текущих 10 дизайнов приложения; язык собран с нуля.

## Сцена (одно предложение)

Разработчик, поздний вечер, за столом, в потоке, дрилит вопросы к собесу короткими
интенсивными подходами — хочет чувствовать себя точным и собранным, инструмент не
должен ни развлекать, ни шуметь.

## Стратегия цвета

Commitment: **restrained → committed**. Один коммитнутый интерактивный цвет
(**teal signal**) несёт всё взаимодействие; поверхность — прохладный истинно-нейтрал
(осознанно НЕ тёплый крем). Амбер-искра — только для стрика/хайлайта (≤5% площади).
Семантика (success-green / error-red) держится в стороне от signal-teal по hue, чтобы
вердикт правильности на экране result не путался с «выбранным».

## Типографика

3 семейства, контрастная пара (гуманистич. serif × геометрич. grotesk) + mono:

- **Newsreader** (`--font-hero`) — вопрос-герой и длинная проза ответа. Serif даёт
  редакционную читаемость сложным формулировкам.
- **Space Grotesk** (`--font-ui`) — весь UI-хром: варианты, кнопки, навигация.
- **JetBrains Mono** (`--font-mono`) — код, бейджи-буквы, кикеры, числа/прогресс.

Шкала ≥1.25 между шагами; hero `clamp(2.1→3.15rem)` (max ~50px, потолок 96px не
трогаем). Трекинг hero −0.025em (не слипается). `text-wrap: balance` на вопросе.
ALL-CAPS в body запрещён; mono-кикер — не tracked-uppercase эйбрау, а функциональный тег.

## Раскладка

- **Полная ширина (мандат юзера, приоритет над центрированием).** На ЛЮБОМ разрешении
  без боковых пустот: хром (шапка/бары/фоны) edge-to-edge, только внутренний `--gutter`.
  НЕ центрированная узкая колонка с симметричными пустыми полями. Проверка:
  `leftVoid/rightVoid` = только gutter и симметрично, хром `span` = 100% vw.
- **App-shell:** основная зона (`.focus-main`) + правый рельс (`.focus-aside`) на широких
  (брейк **1080px**); узкий экран — одна колонка, рельс сверху. Ширину крупных дисплеев
  наполняет реальный контент рельса (сессия/хоткеи/мета; на result — «разбор глубже» +
  действия), а НЕ растянутая строка прозы. Проза держит меру по ch (66ch; hero ~20–32ch)
  ВНУТРИ зоны, структура тянется на всю ширину.
- **Варианты ответа — строки с ПОЛНОЙ границей**, не карточки и не side-stripe.
  Сетка `auto 1fr`: mono-бейдж буквы + текст. Выбранный = teal-кольцо + wash-заливка
  (нейтрально; правильность — только на result).
- **Сессионная рейка:** на широких — вертикальная карта в правом рельсе (прогресс +
  стрик + «завершить»); на узких — слим горизонтальная сверху. Правый жёлоб больше НЕ
  «мёртвый» — он несёт мета-контент (это и есть способ занять ширину без пустот).
- **Один** тема-кикер (mono) над вопросом — функциональный, не эйбрау-на-каждой-секции.

## Motion (emil)

- Вход блоков: `rise` (opacity 0→1, translateY 8px→0), 260ms, ease-out-quart
  `cubic-bezier(0.22,1,0.36,1)`. Варианты — stagger по 40ms (не одинаковый рефлекс:
  входит список, где порядок осмыслен).
- Микро: выбор варианта/hover 120ms. Ничего >300ms.
- `prefers-reduced-motion: reduce` → без анимаций (контент видим по умолчанию, reveal
  лишь усиливает уже-видимое). Транзишены не гейтят видимость.

## Соблюдённые absolute-bans

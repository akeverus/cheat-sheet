Компоненты

UI-примитивы в языке Instrument, каждый — во всех состояниях. Интерактивные состояния (hover/active/focus) показаны demo-классами, зеркалящими реальные :hover/:active/:focus-visible — чтобы весь спектр был виден статически. Источник правды состояний — прод base.css.

Вариант ответа (MCQ)

Ключевой примитив .opt: буква-бейдж + индикатор-форма. Статус несётся формой + цветом, не только цветом. default → hover → selected → focus → correct → incorrect.

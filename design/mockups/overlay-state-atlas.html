Оверлеи

Диалоги, панели и всплывающие поверхности в языке Instrument. Панели показаны раскрытыми на затемнённой сцене; общий scaffold (scrim, focus-trap, Esc, возврат фокуса) — в легенде внизу. Живой демо диалога — кнопкой ниже.

Модальный диалог

Немодальная по смыслу справка, поданная модально. Прод: shell · #kbd-help-overlay = role="dialog" + aria-modal="true" + aria-labelledby/describedby, открытие по ?, focus-trap, Esc, возврат фокуса на триггер.

Disclosure и tooltip

Нативные лёгкие раскрытия. Disclosure: error «Подробности для разработчика», flashcard «Показать ответ». Tooltip: нативный title на icon-кнопках + keyboard-hint.

Кандидаты языка (не в проде)

Паттерны из state-family §7 (menus, popovers), которых в текущем проде нет. Даны как заготовки языка на случай появления сценария — чтобы стиль был готов заранее, а не изобретался на месте.

Точность по теме

Доля верных ответов за всё время. Немодальный поповер: закрывается по клику вне и Esc, фокус не запирается.

Общий scaffold оверлея

Что разделяют dialog и alertdialog (модальные). Drawer/disclosure/popover — облегчённые (не запирают фокус).

Scrim — color-mix(in oklab, var(--ink) 42%, transparent)

Затемнение фона, клик по нему закрывает немодальные; модальные — только явной кнопкой/Esc.

Focus-trap — модальные

Tab циклится внутри панели; фон получает inert/aria-hidden.

Esc — закрытие

Диалоги и поповеры закрываются по Esc; alertdialog — тоже (эквивалент «Отмена»).

Возврат фокуса

После закрытия фокус возвращается на элемент-триггер (aria-haspopup).

Роли

dialog — обычный; alertdialog — требует ответа; menu — menu/menuitem.

Motion

Pop-появление --dur-2 --ease-out; отключается под prefers-reduced-motion.

Живой диалог

Scrim + focus-trap + Esc. Tab не выходит за пределы.

# CS-20260829-044 — выжимка forensic-аудита

Полный документ: `docs/redesign/01-forensic-audit.md` (755+ строк, 8 рубрик §4,
18 экранов §5, 8 режимов §6, живая ultrawide-матрица §17). Этот файл — 10-15
главных находок с якорями, не дублирует документ целиком.

## Главные находки

1. **Login (экран №8 из 18) недостижим в дефолтном режиме.** `LoginController`
   требует `app.security.mode=multi`, а дефолт — `local`
   (`modules/quiz-app/src/main/resources/application.yml:143`); живой замер —
   `curl /login` → `HTTP 404`. Снят только после явного
   `APP_SECURITY_MODE=multi` override.
2. **`app.security.mode=multi` требует входа для GET-навигации**, хотя
   собственная документация называет это «mutating endpoints require auth».
   Живой замер: `curl /stats` в `multi` → `302 → /login`.
3. **Дефолтный пресет экрана `laptop` не учитывает реальный вьюпорт.**
   `readScreenPreset()` без сохранённого выбора всегда `laptop`, независимо от
   ширины окна — на ultrawide это оставляет 30-33% ширины пустой на 4 из 4
   проверенных страниц без листинга (`data/space-metrics.json`).
4. **Голдены покрывают 4 экрана из 18 и 0 режимов из 8.**
   `e2e/visual-baselines/chromium` — 14 снимков (home/train/settings/stats).
   Ни один `InterviewMode`-воркспейс, ни ultrawide-вьюпорт не защищён
   пиксельно.
5. **`static/css/base.css` — сирота манифеста.** 17-строчный `@import`-агрегатор,
   явно исключён из ленты тестом (`TemplateFragmentContractTest`), но ни одна
   `<link>`-ссылка на него не найдена — «намеренно вне ленты» неотличимо от
   «никем не используется».
6. **8 pixel-*.md досье решений (`docs/css-decisions/`) описывают снесённый
   pixel-слой** (снят коммитом `b56bf4c6`, FOLIO) — устарели целиком.
7. **`.sdlc/CS-20260828-003/report.md` и все его 50 PNG сделаны ДО FOLIO** —
   весь визуальный материал предыдущей разведки показывает несуществующий
   дизайн.
8. **`design/mockups/feedback-state-atlas.html:66` цитирует несуществующую
   строку 1275 файла `base.css`** — мокап не обновлялся с момента расщепления
   файла на модули.
9. **Два глифа режимов называются не по имени режима**: CODE_CHALLENGE →
   `#mode-forge`, MARATHON → `#mode-path` (`templates/fragments/icons.html:68,70`)
   — недокументированный разрыв словаря.
10. **`utilities-core.css` и `components-signatures.css`** — единственные два
    CSS без досье решения И без содержательного объясняющего комментария
    (только провенанс «Wave C split from base.css»).
11. **`css-bundle-manifest.txt` + `CssBundleService` + `TemplateFragmentContractTest`
    — рабочий, проверенный треугольник целостности каскада**, 0 реальных
    протечек (`python3 scripts/css-leak-audit.py` — «carriers: OK»).
12. **74 UI-контракт-теста — не документация, а регрессионный барьер** с
    измеренными до/после числами (`UltrawideWorkspaceContractTest`,
    `ScreenPresetContractTest`) — редизайн обязан считаться с этим фундаментом,
    не сносить его молча.
13. **`/review` — самостоятельный экран без строки в §5 и без теста**, при
    собственной композиции (не копия Focus).
14. **`pages-focus.css` (2205 строк) и `shell.css` (1084 строки)** — два
    самых больших и самых рискованных CSS-файла проекта, оба с историей
    многораундовых замеров прямо в комментариях (переусложнены не гипотетически).

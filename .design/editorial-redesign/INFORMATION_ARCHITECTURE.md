# Information Architecture: cheat-sheet quiz (Editorial-редизайн)

> Полный IA-реворк. Маршруты/вью-имена СТАБИЛЬНЫ (контракт §1), переосмысляем опыт и
> навигацию ВНУТРИ них. Главная цель — сделать **Фокус** самодостаточным центром, убрать
> дублирование навигации, починить тупики.

## Site Map

```
Фокус /                         ← 80% времени: чтение вопроса → ответ/оценка
  ├─ Тренировка   /training      (функц. алиас / — не в навигации)
  └─ Повтор ошибок /review        (reviewMode; вход через действия, не таб)
Аналитика /stats                ← прогресс, темы, прогноз, пробелы
Настройки /settings             ← настройка сессии + данные (экспорт, сброс)
Результат /answer → result      ← разбор MCQ-ответа (транзитный, не в навигации)
Сводка сессии /session-summary  ← итоги после «Завершить» (с реальными действиями)
Ошибка /error                   ← статусные страницы
Экспорт /export?format=json|csv  ← выгрузка (ссылки в Настройках и шапке Аналитики)
```

## Navigation Model

**Один навигационный компонент на всех экранах** (удаляем дубль `focus-surface-tabs.html`).

- **Primary navigation (макс. 3):** `Фокус /` · `Аналитика /stats` · `Настройки /settings`.
  Живёт в шапке, видна ВЕЗДЕ (`showPrimaryNav=true` на каждой странице, конец рассинхрона).
  Активный раздел подсвечивается (`activePage`, `aria-current="page"`). На транзитных экранах
  (result, session-summary) активна логическая секция (Фокус).
- **Secondary navigation (контекстная, внутри экрана):**
  - *Фокус:* раскрывающаяся панель **«Настроить сессию»** (фильтры + режим + кол-во + Старт) —
    делает Фокус самодостаточным, без ухода в Настройки.
  - *Аналитика:* якорные секции (Прогресс · Темы · Прогноз · Пробелы) + поиск как утилита.
  - *Сводка:* блок действий (Повторить ошибки · Новая сессия · Аналитика).
- **Utility navigation:** тема-тогл (всегда в шапке справа); экспорт JSON/CSV (в Настройках →
  «Данные» и компактно в шапке Аналитики); «Завершить сессию» (в строке прогресса, когда сессия активна).
- **Mobile navigation:** шапка сворачивается; 3 пункта остаются видимыми как компактный ряд
  (их всего три — гамбургер не нужен). Тема-тогл — иконка 44×44. Строка прогресса липкая сверху
  во время активной сессии. Никакого нижнего таб-бара (web, не нативный мобайл).

## Content Hierarchy

### Фокус `/` (главный экран)
1. **Текущий вопрос** — заголовок-сериф крупно, тело вопроса, опц. код/диаграмма. Главный герой.
2. **Действие** — MCQ-варианты + «Проверить» ИЛИ флешкарта «Показать ответ» → самооценка. По центру внимания.
3. **Строка прогресса сессии** — «Q14 / 50», точность, «Завершить» (липкая, тонкая, вторична).
4. **«Настроить сессию»** — свёрнутая панель (фильтры/режим/кол-во/старт); раскрывается по клику.
5. **Empty-state** (нет вопроса) — самодостаточный: тут же предложить запустить сессию/сменить фильтр,
   НЕ выталкивать в Настройки.

### Результат `/answer → result` (после MCQ-ответа)
1. **Вердикт** — ✅/❌ крупно + правильный вариант.
2. **Разбор по вариантам** — почему верно/неверно (per-option explanation).
3. **Пояснение** — длинный markdown-разбор (reading-сериф, 60–72ch), опц. диаграмма/код.
4. **Уверенность** — самооценка (confidence) — компактно.
5. **Доп. анализ** (по запросу) — takeaway / code-trace / сравнение / похожие вопросы. Прогрессивно.
6. **Дальше** — «Следующий вопрос →» (заметная), «Завершить» (в строке прогресса).

### Аналитика `/stats`
1. **Сводка прогресса** — stats-grid (Всего/К повтору/Выучено/Верно/Ошибки/Точность) + полоса точности.
2. **Графики** — прогресс и точность по темам (Chart.js). Подпись: «те же данные — в таблице ниже».
3. **Темы (таблица)** — свёрнута до N строк, «Показать все»; колонки с понятными подписями, не только тултипы;
   эзотерику (🔄, Зрелость) — за вторичную видимость/тултип.
4. **Прогноз повторов** — 7 дней.
5. **Пробелы банка** — операционное (для генерации), внизу, визуально отделено.
6. **Утилиты:** поиск по вопросам (вторичный блок), экспорт JSON/CSV (шапка раздела).

### Настройки `/settings`
1. **Настройка сессии** — фильтры (тема/группа/избранные/ошибки/микс/слабые/порядок) + режим + кол-во + «Начать».
2. **Прогресс** — stats-grid + streak (зеркало Аналитики, краткое).
3. **Данные** — экспорт JSON/CSV; сброс банка вариантов (опасное, с подтверждением, визуально отделено).

### Сводка сессии `/session-summary`
1. **Итог** — точность (цвет по порогам), Всего/Верно/Ошибки, длительность.
2. **Действия** (чиним тупик): **Повторить ошибки** (→ /review) · **Новая сессия** (→ Настройки/Старт) ·
   **Смотреть аналитику** (→ /stats) · **Продолжить** (→ /).
3. **По темам** — таблица результатов.
4. **Ошибки** — список, **каждая кликабельна** (→ повтор этого вопроса), не мёртвый список.
5. **Рекомендации** — со ссылками в обучение.

## User Flows

### Запуск и прохождение (главный поток)
1. Пользователь на `Фокус /`.
2. Если сессии нет → видит приглашение + панель **«Настроить сессию»** прямо здесь.
   - Выбирает тему/режим/кол-во → **Начать** → `POST /start` → redirect `/`.
3. Видит вопрос. Ветка:
   - **MCQ** (есть варианты): выбирает вариант (клик/1–9) → **Проверить** → `POST /answer` → `result`.
     → читает разбор → **Следующий вопрос →** → `/` со следующим.
   - **Флешкарта** (нет вариантов / режим FLASHCARD): **Показать ответ**
     (browse: клиентом; в сессии: `POST /flashcard-reveal`) → самооценка 1–4 → `POST /flashcard-grade` → `/`.
4. В любой момент **Завершить** (строка прогресса) → `POST /finish` → `/session-summary`.

### После сессии (чиним тупик)
1. `GET /session-summary` показывает итоги + **блок действий**.
2. Решение:
   - «Повторить ошибки» → `/review` (reviewMode) → доучивает промахи.
   - «Новая сессия» → Настройки/панель старта.
   - «Смотреть аналитику» → `/stats`.
   - Клик по ошибке → повтор конкретного вопроса.

### Анализ прогресса
1. `Аналитика /stats`: сводка → графики → темы → прогноз → пробелы.
2. Из «Пробелов»/слабых тем → «Повторить ошибки»/настроить сессию по теме.
3. Экспорт прогресса (JSON/CSV) из шапки раздела.

## Content Growth Plan

- **Темы** (растут): таблица на Аналитике со сверткой (N строк) + «Показать все» + сортировка;
  при дальнейшем росте — поиск/фильтр по теме (поле уже есть). shortName из `topic` (split '/').
- **Прогноз** — фикс. окно 7 дней.
- **Похожие/related** — ограниченный список на result.
- **Ошибки сессии** — ограничены размером сессии; кликабельны.

## URL Strategy

- Паттерн маршрутов СТАБИЛЕН (контракт): `/`, `/training`, `/review`, `/settings`, `/stats`,
  `/answer`(POST), `/start`(POST), `/finish`(POST), `/session-summary`, `/settings/reset-options`(POST),
  `/export`.
- **Query-параметры фильтра** (единый набор): `topic`, `group`, `important`, `onlyWrong`, `shuffle`,
  `weakTopics`, `ordered`, `mode`, `excludeQuestionId`, `count`(start), `q`(stats search).
  Один словарь фильтров на все экраны — конец тройного дублирования полей (DRY-фрагмент формы фильтра).
- `/review` — повтор ошибок (вход через действия, не таб). `/training` — алиас `/` (не светим в навигации).
- Экспорт: `/export?format=json|csv`.

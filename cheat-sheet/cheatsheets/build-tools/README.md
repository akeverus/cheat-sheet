# Инструменты сборки (Build Tools)

**Комплексные руководства по инструментам сборки: Maven, Gradle**

## 📋 Описание

Этот раздел содержит детальные руководства по инструментам сборки Java проектов: Apache Maven и Gradle. Каждый инструмент покрыт от основ до продвинутых тем.

## 📚 Структура раздела

### 🐘 [Maven Advanced](maven-advanced.md)
**Apache Maven**

- **Maven Advanced** - Продвинутые темы Maven
- **Maven Plugins** - Maven плагины
- **Maven Multi-module** - Многомодульные проекты
- **Maven Dependencies** - Управление зависимостями

### 🎯 [Gradle Advanced](gradle-advanced.md)
**Gradle Build Tool**

- **Gradle Advanced** - Продвинутые темы Gradle
- **Gradle Plugins** - Gradle плагины
- **Gradle Multi-project** - Многопроектные сборки
- **Gradle Performance** - Оптимизация производительности

## 🎯 Для кого этот раздел

### Java Developers
- **Выбор инструмента** - Maven vs Gradle
- **Настройка сборки** - конфигурация проектов
- **Управление зависимостями** - dependency management

### Build Engineers
- **Оптимизация сборки** - производительность
- **CI/CD интеграция** - автоматизация сборки
- **Best practices** - лучшие практики

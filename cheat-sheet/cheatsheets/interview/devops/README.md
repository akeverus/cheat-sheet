# Вопросы на собеседовании: DevOps

**Комплексные материалы для подготовки к техническим собеседованиям по DevOps**

## 📋 Описание

Этот раздел содержит детальные руководства по вопросам собеседований по DevOps: Docker, Kubernetes, CI/CD, мониторинг, инфраструктура. Каждый файл содержит минимум 1000 строк описательного текста на русском языке, практические примеры, Best Practices и Troubleshooting секции.

## 📚 Структура раздела

### 🐳 [Docker](docker-interview.md)
**Вопросы по Docker**

- **[Docker Interview](docker-interview.md)** 🟡 - требует расширения до 1000+ строк
  - Контейнеризация, образы, Docker Compose
  - Best Practices и Troubleshooting

### ☸️ [Kubernetes](kubernetes-interview.md)
**Вопросы по Kubernetes**

- **[Kubernetes Interview](kubernetes-interview.md)** 🟡 - требует расширения
  - Pods, Deployments, Services
  - ConfigMaps, Secrets, Volumes

### 🔧 [Git](git-interview.md)
**Вопросы по Git**

- **[Git Interview](git-interview.md)** 🟡 - требует расширения
  - Ветвление, слияние, rebase
  - Best Practices и workflow

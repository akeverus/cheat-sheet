## 📋 Описание

Этот раздел содержит детальные руководства по вопросам собеседований по backend фреймворкам: Spring Framework, Micronaut, Quarkus. Каждый файл содержит минимум 1000 строк описательного текста на русском языке, практические примеры на Java + Spring, Best Practices и Troubleshooting секции.

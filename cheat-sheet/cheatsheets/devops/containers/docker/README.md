# Docker

**Комплексные руководства по Docker: контейнеризация приложений**

## 📋 Описание

Этот раздел содержит детальные руководства по Docker - платформе для контейнеризации приложений. Материалы покрывают создание образов, управление контейнерами, Docker Compose, best practices для Java приложений.

## 📚 Структура раздела

### Основные темы
- **Docker Basics** - Основы Docker
- **Docker Images** - Создание и управление образами
- **Docker Containers** - Управление контейнерами
- **Docker Compose** - Оркестрация нескольких контейнеров
- **Docker & Spring Boot** - Контейнеризация Spring Boot приложений
- **Docker Networking** - Сети в Docker
- **Docker Volumes** - Управление данными

## 🎯 Для кого этот раздел

### Backend Developers
- **Контейнеризация приложений** - Docker для Java/Spring Boot
- **Docker Compose** - локальная разработка с БД
- **Best practices** - оптимизация образов

### DevOps Engineers
- **Создание образов** - Dockerfile и multi-stage builds
- **Оркестрация** - Docker Compose и Swarm
- **Оптимизация** - размер образов и производительность

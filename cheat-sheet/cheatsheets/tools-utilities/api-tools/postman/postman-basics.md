## Введение в Postman

**Postman** — инструмент для разработки, тестирования и документирования API.

### Основные возможности

- Создание HTTP запросов
- Управление коллекциями
- Автоматизация тестов
- Генерация документации

## Создание запросов

```http
GET https://api.example.com/users
Authorization: Bearer token
Content-Type: application/json
```

## Коллекции

Коллекции позволяют организовывать запросы по проектам и командам.

## Переменные и окружения

Использование переменных для разных окружений (dev, staging, prod).

## Автоматизация

Postman позволяет создавать автоматические тесты и запускать их через CLI.

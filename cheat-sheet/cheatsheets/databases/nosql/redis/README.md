# Redis

**Комплексные руководства по Redis: кэширование, очереди, pub/sub**

## 📋 Описание

Этот раздел содержит детальные руководства по Redis - in-memory структуре данных, используемой как база данных, кэш и брокер сообщений. Материалы покрывают структуры данных Redis, паттерны использования, оптимизацию производительности.

## 📚 Структура раздела

### Основные темы
- **Redis Basics** - Основы работы с Redis
- **Redis Data Structures** - Структуры данных (Strings, Lists, Sets, Hashes, Sorted Sets)
- **Redis Patterns** - Паттерны использования (кэширование, очереди, pub/sub)
- **Redis Performance** - Оптимизация производительности
- **Redis Clustering** - Кластеризация и репликация

## 🎯 Для кого этот раздел

### Backend Developers
- **Кэширование** - стратегии кэширования с Redis
- **Очереди** - использование Redis как message broker
- **Session Storage** - хранение сессий

### DevOps Engineers
- **Настройка Redis** - конфигурация и оптимизация
- **Мониторинг** - мониторинг производительности
- **Кластеризация** - настройка Redis Cluster

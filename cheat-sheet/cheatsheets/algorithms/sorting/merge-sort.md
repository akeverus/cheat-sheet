## Описание алгоритма

Сортировка слиянием - один из наиболее эффективных методов сортировки, основанный на парадигме «разделяй и властвуй».

Сортировка слиянием - это алгоритм «разделяй и властвуй», в котором мы сначала делим проблему на подзадачи. Когда решения для подзадач готовы, мы объединяем их вместе, чтобы получить окончательное решение проблемы.

Мы можем легко реализовать этот алгоритм с помощью рекурсии, так как мы имеем дело с подзадачами, а не с основной проблемой.

## Принцип работы

Мы можем описать алгоритм как следующий двухэтапный процесс:

1. **Divide (Разделение):** на этом шаге мы делим входной массив на 2 половины, причем точка опоры является средней точкой массива. Этот шаг выполняется рекурсивно для всех полумассивов до тех пор, пока не останется разделяемых полумассивов.

2. **Conquer (Завоевание):** на этом этапе мы сортируем и объединяем разделенные массивы снизу вверх и получаем отсортированный массив.

Если мы внимательно посмотрим на процесс, то увидим, что массив рекурсивно делится на две половины, пока размер не станет равным 1. Как только размер станет равным 1, в действие вступают процессы слияния, которые начинают объединять массивы обратно при сортировке.

### Пример работы

Для примера массива `{10, 6, 8, 5, 7, 3, 4}` процесс будет следующим:

```
Разделение:
{10, 6, 8, 5, 7, 3, 4}
├─ {10, 6, 8} ──────────┐
│  ├─ {10, 6}          │
│  │  ├─ {10}         │
│  │  └─ {6}          │
│  └─ {8}             │
└─ {5, 7, 3, 4} ───────┘
   ├─ {5, 7}
   │  ├─ {5}
   │  └─ {7}
   └─ {3, 4}
      ├─ {3}
      └─ {4}

Слияние:
{6, 10} + {8} → {6, 8, 10}
{5, 7} + {3, 4} → {3, 4, 5, 7}
{6, 8, 10} + {3, 4, 5, 7} → {3, 4, 5, 6, 7, 8, 10}
```

## Java Implementation

Для реализации мы напишем функцию `mergeSort`, которая принимает входной массив и его длину в качестве параметров. Это будет рекурсивная функция, поэтому нам нужна база и рекурсивные условия.

Базовое условие проверяет, равна ли длина массива 1, и оно просто возвращается. В остальных случаях будет выполнен рекурсивный вызов.

Для рекурсивного случая мы получаем средний индекс и создаем два временных массива, `l[]` и `r[]`. Затем мы рекурсивно вызываем функцию `mergeSort` для обоих подмассивов:

```java
public static void mergeSort(int[] a, int n) {
    if (n < 2) {
        return;
    }
    
    int mid = n / 2;
    int[] l = new int[mid];
    int[] r = new int[n - mid];
    
    for (int i = 0; i < mid; i++) {
        l[i] = a[i];
    }
    
    for (int i = mid; i < n; i++) {
        r[i - mid] = a[i];
    }
    
    mergeSort(l, mid);
    mergeSort(r, n - mid);
    merge(a, l, r, mid, n - mid);
}
```

Затем мы вызываем функцию слияния, которая принимает входные данные и оба подмассива, а также начальный и конечный индексы обоих подмассивов.

Функция слияния сравнивает элементы обоих подмассивов один за другим и помещает меньший элемент во входной массив.

Когда мы достигаем конца одного из подмассивов, остальные элементы из другого массива копируются во входной массив, тем самым давая нам окончательный отсортированный массив:

```java
public static void merge(int[] a, int[] l, int[] r, int left, int right) {
    int i = 0, j = 0, k = 0;
    
    while (i < left && j < right) {
        if (l[i] <= r[j]) {
            a[k++] = l[i++];
        } else {
            a[k++] = r[j++];
        }
    }
    
    while (i < left) {
        a[k++] = l[i++];
    }
    
    while (j < right) {
        a[k++] = r[j++];
    }
}
```

## Kotlin Implementation

В Kotlin алгоритм Merge Sort может быть реализован следующим образом:

```kotlin
fun mergeSort(arr: IntArray, n: Int = arr.size) {
    if (n < 2) return

    val mid = n / 2
    val l = IntArray(mid)
    val r = IntArray(n - mid)

    for (i in 0 until mid) {
        l[i] = arr[i]
    }

    for (i in mid until n) {
        r[i - mid] = arr[i]
    }

    mergeSort(l, mid)
    mergeSort(r, n - mid)
    merge(arr, l, r, mid, n - mid)
}

fun merge(a: IntArray, l: IntArray, r: IntArray, left: Int, right: Int) {
    var i = 0
    var j = 0
    var k = 0

    while (i < left && j < right) {
        if (l[i] <= r[j]) {
            a[k++] = l[i++]
        } else {
            a[k++] = r[j++]
        }
    }

    while (i < left) {
        a[k++] = l[i++]
    }

    while (j < right) {
        a[k++] = r[j++]
    }
}
```

Использование:

```kotlin
fun main() {
    val array = intArrayOf(5, 1, 6, 2, 3, 4)
    mergeSort(array)
    println(array.contentToString()) // [1, 2, 3, 4, 5, 6]
}
```

### Функциональный стиль

В Kotlin можно также использовать более функциональный подход:

```kotlin
fun mergeSortFunctional(list: List<Int>): List<Int> {
    if (list.size <= 1) return list

    val mid = list.size / 2
    val left = mergeSortFunctional(list.subList(0, mid))
    val right = mergeSortFunctional(list.subList(mid, list.size))

    return mergeLists(left, right)
}

fun mergeLists(left: List<Int>, right: List<Int>): List<Int> {
    var i = 0
    var j = 0
    val result = mutableListOf<Int>()

    while (i < left.size && j < right.size) {
        if (left[i] <= right[j]) {
            result.add(left[i++])
        } else {
            result.add(right[j++])
        }
    }

    while (i < left.size) {
        result.add(left[i++])
    }

    while (j < right.size) {
        result.add(right[j++])
    }

    return result
}
```

Использование:

```kotlin
fun main() {
    val list = listOf(5, 1, 6, 2, 3, 4)
    val sorted = mergeSortFunctional(list)
    println(sorted) // [1, 2, 3, 4, 5, 6]
}
```

## Сложность

Поскольку сортировка слиянием является рекурсивным алгоритмом, временная сложность может быть выражена в виде следующего рекурсивного соотношения:

```
T(n) = 2T(n/2) + O(n)
```

`2T(n/2)` соответствует времени, необходимому для сортировки подмассивов, а `O(n)` - времени для слияния всего массива.

При решении временная сложность составит `O(n*log(n))`.

### Временная сложность

- **Худший случай:** O(n*log(n))
- **Средний случай:** O(n*log(n))
- **Лучший случай:** O(n*log(n))

Это верно для наихудшего, среднего и наилучшего случаев, поскольку алгоритм всегда будет делить массив на два, а затем объединять.

### Пространственная сложность

- **Все случаи:** O(n) - требуется дополнительная память для временных массивов при каждом рекурсивном вызове

## Особенности

- **Стабильность:** Merge Sort является стабильным алгоритмом сортировки (сохраняет относительный порядок элементов с одинаковыми значениями)
- **Гарантированная производительность:** Всегда работает за O(n*log(n)), независимо от входных данных
- **Параллелизация:** Легко распараллеливается благодаря независимости подзадач
- **Внешняя сортировка:** Хорошо подходит для сортировки больших файлов, которые не помещаются в память

## Применение

Merge Sort особенно полезен в следующих случаях:

- Когда требуется стабильная сортировка
- Когда нужна гарантированная производительность O(n*log(n))
- Для сортировки связанных списков (не требует дополнительной памяти)
- Для внешней сортировки больших объемов данных

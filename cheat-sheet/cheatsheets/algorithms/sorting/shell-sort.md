# Shell Sort

Кратко: сортировка Шелла - это улучшенная версия сортировки вставками, которая использует интервалы (gaps) для сортировки элементов на расстоянии друг от друга, что позволяет быстрее перемещать элементы в правильные позиции.

## Описание алгоритма

Сортировка Шелла основана на алгоритме сортировки вставками и относится к группе очень эффективных алгоритмов. Как правило, алгоритм разбивает исходный набор на более мелкие подмножества, а затем каждое из них сортируется с помощью сортировки вставками.

Но то, как он создает подмножества, не является простым. Он не выбирает соседние элементы для формирования подмножества, как можно было бы ожидать. Скорее, сортировка оболочки использует так называемый интервал или промежуток для создания подмножества. Например, если у нас есть разрыв I, это означает, что одно подмножество будет содержать элементы, которые находятся на расстоянии I позиций.

## Принцип работы

Во-первых, алгоритм сортирует элементы, находящиеся далеко друг от друга. Затем зазор становится меньше, и сравниваются более близкие элементы. Таким образом, некоторые элементы, которые не находятся в правильном положении, могут быть расположены быстрее, чем если бы мы создали подмножества из соседних элементов.

### Пример работы

Давайте посмотрим это на примере с промежутками 3 и 1 и несортированным списком из 9 элементов:

**Исходный массив:** `[41, 15, 82, 5, 65, 19, 32, 43, 8]`

Если мы будем следовать приведенному выше описанию, на первой итерации у нас будет три подмножества с 3 элементами (выделены одним цветом):

- Подмножество 1 (gap=3): `[41, 5, 32]` → после сортировки: `[5, 32, 41]`
- Подмножество 2 (gap=3): `[15, 65, 43]` → после сортировки: `[15, 43, 65]`
- Подмножество 3 (gap=3): `[82, 19, 8]` → после сортировки: `[8, 19, 82]`

После сортировки каждого из подмножеств на первой итерации список будет выглядеть так:

`[5, 15, 8, 32, 43, 19, 41, 65, 82]`

Мы можем заметить, что, хотя у нас еще нет отсортированного списка, элементы теперь ближе к желаемым позициям.

Наконец, нам нужно сделать еще одну сортировку с приращением на единицу (gap=1), и это на самом деле базовая сортировка вставками. Количество операций сдвига, которые нам нужно выполнить для сортировки списка, теперь меньше, чем было бы, если бы мы не делали первую итерацию:

**Финальный результат:** `[5, 8, 15, 19, 32, 41, 43, 65, 82]`

## Последовательности интервалов

Как мы уже упоминали, сортировка оболочки имеет уникальный способ выбора последовательностей пробелов. Это трудная задача, и мы должны быть осторожны, чтобы не выбрать слишком мало или слишком много пробелов.

Наиболее часто используемые последовательности:

1. **Последовательность Shell:** N/2, N/4, ..., 1 (непрерывное деление на 2)
2. **Последовательность Knuth:** (3^k - 1) / 2
3. **Последовательность Sedgewick:** 1, 5, 19, 41, 109, ...

В нашей реализации мы будем использовать исходную последовательность Shell для увеличения интервала: N/2, N/4, …, 1 (continuously dividing by 2)

## Java Implementation

Сама реализация не слишком сложна:

```java
public void sort(int arrayToSort[]) {
    int n = arrayToSort.length;
    
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int key = arrayToSort[i];
            int j = i;
            
            while (j >= gap && arrayToSort[j - gap] > key) {
                arrayToSort[j] = arrayToSort[j - gap];
                j -= gap;
            }
            
            arrayToSort[j] = key;
        }
    }
}
```

Сначала мы создали последовательность пробелов с помощью цикла for, а затем выполнили сортировку вставками для каждого размера пробела.

## Kotlin Implementation

### Базовая реализация (последовательность Shell)

```kotlin
fun shellSortK(arrayToSort: IntArray) {
    val n = arrayToSort.size
    
    var gap = n / 2
    while (gap > 0) {
        for (i in gap until n) {
            val key = arrayToSort[i]
            var j = i
            
            while (j >= gap && arrayToSort[j - gap] > key) {
                arrayToSort[j] = arrayToSort[j - gap]
                j -= gap
            }
            
            arrayToSort[j] = key
        }
        gap /= 2
    }
}
```

### Реализация с последовательностью Knuth

```kotlin
fun shellSortKnuthK(arrayToSort: IntArray) {
    val n = arrayToSort.size
    
    // Генерация последовательности Knuth: (3^k - 1) / 2
    val gaps = generateSequence(1) { it * 3 + 1 }
        .takeWhile { it < n }
        .toList()
        .reversed()
    
    for (gap in gaps) {
        for (i in gap until n) {
            val key = arrayToSort[i]
            var j = i
            
            while (j >= gap && arrayToSort[j - gap] > key) {
                arrayToSort[j] = arrayToSort[j - gap]
                j -= gap
            }
            
            arrayToSort[j] = key
        }
    }
}
```

### Реализация с последовательностью Sedgewick

```kotlin
fun shellSortSedgewickK(arrayToSort: IntArray) {
    val n = arrayToSort.size
    
    // Последовательность Sedgewick: 1, 5, 19, 41, 109, ...
    val sedgewickGaps = generateSequence(1) { gap ->
        when {
            gap <= 1 -> 5
            gap == 5 -> 19
            gap == 19 -> 41
            gap == 41 -> 109
            else -> gap * 4 + 1
        }
    }
        .takeWhile { it < n }
        .toList()
        .reversed()
    
    for (gap in sedgewickGaps) {
        for (i in gap until n) {
            val key = arrayToSort[i]
            var j = i
            
            while (j >= gap && arrayToSort[j - gap] > key) {
                arrayToSort[j] = arrayToSort[j - gap]
                j -= gap
            }
            
            arrayToSort[j] = key
        }
    }
}
```

### Функциональный стиль (возвращает новый массив)

```kotlin
fun shellSortFunctionalK(input: List<Int>): List<Int> {
    val arr = input.toMutableList()
    val n = arr.size
    
    var gap = n / 2
    while (gap > 0) {
        for (i in gap until n) {
            val key = arr[i]
            var j = i
            
            while (j >= gap && arr[j - gap] > key) {
                arr[j] = arr[j - gap]
                j -= gap
            }
            
            arr[j] = key
        }
        gap /= 2
    }
    
    return arr
}
```

### Пример использования

```kotlin
fun main() {
    val input = intArrayOf(41, 15, 82, 5, 65, 19, 32, 43, 8)
    
    // Базовая версия (последовательность Shell)
    val arr1 = input.copyOf()
    shellSortK(arr1)
    println(arr1.contentToString()) 
    // [5, 8, 15, 19, 32, 41, 43, 65, 82]
    
    // Последовательность Knuth
    val arr2 = input.copyOf()
    shellSortKnuthK(arr2)
    println(arr2.contentToString())
    
    // Последовательность Sedgewick
    val arr3 = input.copyOf()
    shellSortSedgewickK(arr3)
    println(arr3.contentToString())
    
    // Функциональный стиль
    val sorted = shellSortFunctionalK(input.toList())
    println(sorted) // [5, 8, 15, 19, 32, 41, 43, 65, 82]
}
```

## Сложность

Как правило, алгоритм сортировки Шелла очень эффективен для списков среднего размера. Сложность определить сложно, так как она во многом зависит от последовательности пропусков, но временная сложность варьируется от O(N) до O(N²).

### Временная сложность

- **Лучший случай:** O(n*log(n)) - с последовательностью Sedgewick
- **Средний случай:** O(n^1.5) - с последовательностью Shell
- **Худший случай:** O(n²) - с последовательностью Shell

Сложность сильно зависит от выбранной последовательности интервалов. Последовательность Shell дает O(n²) в худшем случае, в то время как более продвинутые последовательности (например, Sedgewick) могут дать O(n*log(n)) в лучшем случае.

### Пространственная сложность

- **Все случаи:** O(1) - сортировка выполняется на месте, требуется только константная дополнительная память

## Особенности

- **Улучшенная сортировка вставками:** Shell Sort - это оптимизация сортировки вставками
- **In-place:** Сортировка выполняется на месте, не требует дополнительной памяти
- **Нестабильность:** Shell Sort не является стабильным алгоритмом
- **Зависимость от последовательности:** Производительность сильно зависит от выбранной последовательности интервалов

## Применение

Shell Sort полезен в следующих случаях:

- Для средних размеров массивов (до нескольких тысяч элементов)
- Когда требуется in-place сортировка
- В системах с ограниченной памятью
- Как промежуточный шаг в более сложных алгоритмах

## Сравнение с другими алгоритмами

| Алгоритм | Лучший | Средний | Худший | Память | Стабильность |
|----------|--------|---------|--------|--------|--------------|
| Shell Sort | O(n*log(n)) | O(n^1.5) | O(n²) | O(1) | Нет |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) | Да |
| Merge Sort | O(n*log(n)) | O(n*log(n)) | O(n*log(n)) | O(n) | Да |

## Преимущества и недостатки

### Преимущества

- Эффективнее, чем сортировка вставками для больших массивов
- In-place алгоритм
- Легко реализуется
- Хорошо работает для средних размеров данных

### Недостатки

- Сложность зависит от последовательности интервалов
- Нестабильный алгоритм
- Может быть медленнее, чем Quick Sort или Merge Sort для больших массивов
- Сложность анализа производительности

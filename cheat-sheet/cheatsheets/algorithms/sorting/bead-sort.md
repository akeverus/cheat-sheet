## Описание алгоритма

Гравитационная сортировка - это естественный алгоритм сортировки, вдохновленный природными явлениями - в данном случае силой гравитации. Этот алгоритм, также известный как Bead Sort, имитирует силу гравитации для сортировки списка положительных целых чисел.

Идея алгоритма состоит в том, чтобы представлять положительные целые числа с помощью бусинок на вертикальных стержнях и горизонтальных уровнях - аналогично абаку, за исключением того, что каждый уровень представляет одно число входного списка. Следующим шагом является опускание бусинок в самое низкое возможное положение, в результате чего счеты имеют возрастающий порядок чисел.

## Принцип работы

Например, вот процесс сортировки входного списка [4, 2]:

Прикладываем силу тяжести к счету. В результате все бусины после падения окажутся в самом нижнем возможном положении. Результирующее состояние счетов теперь представляет собой возрастающий порядок положительных целых чисел сверху вниз.

На самом деле гравитация сбрасывает все бусины одновременно. Однако в программном обеспечении мы должны имитировать падение шариков в разных итерациях. Далее мы рассмотрим, как мы можем представить счеты в виде двумерного массива и как мы можем имитировать падающие бусинки для сортировки чисел в списке.

## Java Implementation

Чтобы реализовать гравитационную сортировку в программном обеспечении, мы будем следовать псевдокоду в этой статье, чтобы написать код на Java.

### Шаг 1: Поиск максимального значения

Во-первых, нам нужно преобразовать входной список в счеты. Мы будем использовать двумерный массив для представления стержней (столбцов) и уровней (строк) в качестве размеров матрицы. Кроме того, мы будем использовать true или false, чтобы указать шарик или пустую ячейку соответственно.

Прежде чем настраивать наши счеты, давайте найдем размеры матрицы. Количество столбцов m равно самому большому элементу в списке. Поэтому давайте создадим метод для нахождения этого числа:

```java
static int findMax(int[] A) {
    int max = A[0];
    for (int i = 1; i < A.length; i++) {
        if (A[i] > max) {
            max = A[i];
        }
    }
    return max;
}
```

Теперь мы можем присвоить m наибольшее число:

```java
int[] A = {1, 3, 4, 2};
int m = findMax(A);
```

### Шаг 2: Создание счетов

Теперь с помощью m мы можем создать представление счетов. Для этого воспользуемся методом `setupAbacus()`:

```java
static boolean[][] setupAbacus(int[] A, int m) {
    boolean[][] abacus = new boolean[A.length][m];
    
    for (int i = 0; i < abacus.length; i++) {
        int number = A[i];
        for (int j = 0; j < abacus[0].length && j < number; j++) {
            abacus[A.length - 1 - i][j] = true;
        }
    }
    
    return abacus;
}
```

Метод `setupAbacus()` возвращает начальное состояние счетов. Метод проходит по каждой ячейке матрицы, присваивая бусину или пустую ячейку.

На каждом уровне матрицы мы будем использовать i-е число в списке A, чтобы определить количество бусин в ряду. Более того, мы перебираем каждый столбец j, и если число больше, чем индекс j-го столбца, мы помечаем эту ячейку как истинную, чтобы указать бусину. В противном случае цикл завершается досрочно, оставляя остальные ячейки пустыми или ложными в i-й строке.

Создадим счеты:

```java
boolean[][] abacus = setupAbacus(A, m);
```

### Шаг 3: Падение бусин

Теперь мы готовы позволить гравитации отсортировать шарики, опустив их в самые нижние возможные положения:

```java
static void dropBeads(boolean[][] abacus, int[] A, int m) {
    for (int i = 1; i < A.length; i++) {
        for (int j = m - 1; j >= 0; j--) {
            if (abacus[i][j] == true) {
                int x = i;
                while (x > 0 && abacus[x - 1][j] == false) {
                    boolean temp = abacus[x - 1][j];
                    abacus[x - 1][j] = abacus[x][j];
                    abacus[x][j] = temp;
                    x--;
                }
            }
        }
    }
}
```

Первоначально метод `dropBeads()` перебирает каждую ячейку в матрице. Начиная с 1, i - это строка, с которой нужно начинать, так как с самого нижнего уровня 0 не будет ни одной бусины. Справа налево.

На каждой итерации мы проверяем, содержит ли текущая ячейка `abacus[i][j]` бусину. Если это так, мы используем переменную x для хранения текущего уровня падающей бусинки. Мы сбрасываем бусину, уменьшая x до тех пор, пока это не самый нижний уровень, а ячейка ниже является пустым пространством.

### Шаг 4: Преобразование в отсортированный массив

Наконец, нам нужно преобразовать конечное состояние счетов в отсортированный массив. Метод `toSortedList()` принимает счеты в качестве параметра вместе с исходным входным списком и соответствующим образом изменяет массив:

```java
static void toSortedList(boolean[][] abacus, int[] A) {
    int index = 0;
    for (int i = abacus.length - 1; i >= 0; i--) {
        int beads = 0;
        for (int j = 0; j < abacus[0].length && abacus[i][j] == true; j++) {
            beads++;
        }
        A[index++] = beads;
    }
}
```

Мы можем вспомнить, что количество бусин в каждом ряду представляет собой одно число в списке. По этой причине метод перебирает каждый уровень счетов, подсчитывает бусины и присваивает значение списку. Метод устанавливает значения в порядке возрастания, начиная с самого высокого значения строки. Однако, начиная с i = 0, он размещает числа в порядке убывания.

### Полная реализация

Давайте объединим все части алгоритма в один метод `gravitySort()`:

```java
static void gravitySort(int[] A) {
    int m = findMax(A);
    boolean[][] abacus = setupAbacus(A, m);
    dropBeads(abacus, A, m);
    toSortedList(abacus, A);
}
```

### Тестирование

Мы можем подтвердить, что алгоритм работает, создав модульный тест:

```java
@Test
public void givenIntegerArray_whenSortedWithGravitySort_thenGetSortedArray() {
    int[] actual = {9, 9, 100, 3, 57, 12, 3, 78, 0, 2, 2, 40, 21, 9};
    int[] expected = {0, 2, 2, 3, 3, 9, 9, 9, 12, 21, 40, 57, 78, 100};
    GravitySort.sort(actual);
    Assert.assertArrayEquals(expected, actual);
}
```

## Kotlin Implementation

### Вспомогательные методы

```kotlin
private fun findMaxK(A: IntArray): Int {
    var max = A[0]
    for (i in 1 until A.size) {
        if (A[i] > max) {
            max = A[i]
        }
    }
    return max
}

private fun setupAbacusK(A: IntArray, m: Int): Array<BooleanArray> {
    val abacus = Array(A.size) { BooleanArray(m) }
    
    for (i in abacus.indices) {
        val number = A[i]
        for (j in 0 until minOf(abacus[0].size, number)) {
            abacus[A.size - 1 - i][j] = true
        }
    }
    
    return abacus
}

private fun dropBeadsK(abacus: Array<BooleanArray>, A: IntArray, m: Int) {
    for (i in 1 until A.size) {
        for (j in m - 1 downTo 0) {
            if (abacus[i][j]) {
                var x = i
                while (x > 0 && !abacus[x - 1][j]) {
                    val temp = abacus[x - 1][j]
                    abacus[x - 1][j] = abacus[x][j]
                    abacus[x][j] = temp
                    x--
                }
            }
        }
    }
}

private fun toSortedListK(abacus: Array<BooleanArray>, A: IntArray) {
    var index = 0
    for (i in abacus.size - 1 downTo 0) {
        var beads = 0
        var j = 0
        while (j < abacus[0].size && abacus[i][j]) {
            beads++
            j++
        }
        A[index++] = beads
    }
}
```

### Полная реализация

```kotlin
fun gravitySortK(A: IntArray) {
    val m = findMaxK(A)
    val abacus = setupAbacusK(A, m)
    dropBeadsK(abacus, A, m)
    toSortedListK(abacus, A)
}
```

### Пример использования

```kotlin
fun main() {
    val actual = intArrayOf(9, 9, 100, 3, 57, 12, 3, 78, 0, 2, 2, 40, 21, 9)
    val expected = intArrayOf(0, 2, 2, 3, 3, 9, 9, 9, 12, 21, 40, 57, 78, 100)
    
    gravitySortK(actual)
    println(actual.contentEquals(expected)) // true
    println(actual.contentToString())
}
```

## Сложность

Мы видели, что алгоритм гравитационной сортировки влечет за собой много обработки. Поэтому давайте разобьем его на временную и пространственную сложность.

Реализация алгоритма гравитационной сортировки начинается с нахождения максимального числа m во входном списке. Этот процесс представляет собой операцию времени выполнения O(n), поскольку мы проходим через массив один раз. Как только мы получим m, мы установим начальное состояние счетов. Поскольку счеты на самом деле являются матрицей, посещение каждой ячейки в каждой строке и столбце приводит к операции O(m * n), где n - количество строк.

Как только наша установка будет готова, мы должны опустить бусины в максимально низкое положение в матрице, как если бы гравитация воздействовала на наши счеты. Опять же, мы посещаем каждую ячейку в матрице вместе с внутренним циклом, который отбрасывает шарики не более чем на n уровней в каждом столбце. Этот процесс имеет время выполнения O(n * n * m).

Кроме того, мы должны выполнить O(n) дополнительных шагов, чтобы воссоздать наш список на основе отсортированного представления на счетах.

В целом, гравитационная сортировка - это алгоритм O(n * n * m), учитывая его усилия по имитации падения бусинок.

### Временная сложность

- **Лучший случай:** O(n * m) - когда элементы уже отсортированы
- **Средний случай:** O(n * n * m)
- **Худший случай:** O(n * n * m)

где:
- n - количество элементов
- m - максимальное значение в массиве

### Пространственная сложность

- **Все случаи:** O(n * m) - для хранения двумерного массива счетов

Сложность пространства для гравитационной сортировки пропорциональна размеру входного списка и его наибольшему числу. Например, список с количеством элементов n и максимальным числом m требует матричного представления размеров n×m. Следовательно, сложность пространства составляет O(n * m), чтобы выделить дополнительное место в памяти для матрицы.

Тем не менее, мы пытаемся минимизировать пространственную сложность, представляя бусинки и пустые ячейки отдельными битами или числами. А именно, 1 или true указывает на бусину, и аналогично, значение 0 или false означает пустую ячейку.

## Особенности

- **Естественный алгоритм:** Вдохновлен физическим явлением (гравитация)
- **Визуализация:** Легко визуализировать процесс сортировки
- **Ограничения:** Работает только с положительными целыми числами
- **Неэффективность:** Высокая временная и пространственная сложность

## Применение

Bead Sort в основном используется для:

- Демонстрации концепции естественных алгоритмов
- Образовательных целей
- Визуализации процесса сортировки
- Многопоточных реализаций (может быть эффективнее)

## Ограничения

- Работает только с положительными целыми числами
- Очень высокая временная сложность O(n² * m)
- Высокая пространственная сложность O(n * m)
- Не подходит для практического использования в большинстве случаев

## Сравнение с другими алгоритмами

| Алгоритм | Временная сложность | Пространственная сложность | Применение |
|----------|---------------------|----------------------------|------------|
| Bead Sort | O(n² * m) | O(n * m) | Образовательные цели |
| Bubble Sort | O(n²) | O(1) | Простые случаи |
| Quick Sort | O(n*log(n)) | O(log(n)) | Общее применение |

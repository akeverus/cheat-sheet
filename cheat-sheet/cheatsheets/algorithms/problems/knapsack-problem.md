## Описание алгоритма

Задача о рюкзаке - это задача комбинаторной оптимизации, имеющая множество приложений. В этом уроке мы решим эту проблему на Java.

В задаче о рюкзаке у нас есть набор предметов. Каждый предмет имеет вес и ценность.

Мы хотим положить эти предметы в рюкзак. Однако у него есть ограничение по весу.

Поэтому нам нужно выбрать предметы, общий вес которых не превышает предела веса, а их общая стоимость как можно выше.

### Пример

Предметы:
- Предмет 1: вес 5 кг, стоимость $10
- Предмет 2: вес 6 кг, стоимость $30
- Предмет 3: вес 3 кг, стоимость $15

Ограничение веса: 10 кг

Лучшее решение: выбрать предмет весом 5 кг и предмет весом 6 кг, что дает максимальную стоимость в $40 в пределах ограничения веса.

## Формулировка задачи

Задача о рюкзаке имеет несколько вариантов. В этом уроке мы сосредоточимся на задаче о рюкзаке 0-1. В задаче о рюкзаке 0-1 каждый предмет нужно либо выбрать, либо оставить. Мы не можем взять часть суммы товара. Кроме того, мы не можем брать предмет несколько раз.

Давайте теперь формализуем задачу о рюкзаке 0-1 в математической записи. Учитывая набор из n элементов и предел веса W, мы можем определить задачу оптимизации как:

```
maximize: Σ(vi × xi)
subject to: Σ(wi × xi) ≤ W
where: xi ∈ {0, 1}
```

где:
- vi - стоимость i-го предмета
- wi - вес i-го предмета
- xi - переменная выбора (1 если выбран, 0 если нет)
- W - максимальный вес рюкзака

Эта задача является NP-трудной. Следовательно, в настоящее время не существует алгоритма с полиномиальным временем для ее решения. Однако для этой задачи существует алгоритм псевдополиномиального времени, использующий динамическое программирование.

## Java Implementation

### Рекурсивное решение

Мы можем использовать формулу рекурсии, чтобы решить эту проблему:

```
M(n, w) = max(M(n-1, w), M(n-1, w-wn) + vn)
```

В этой формуле M(n, w) - оптимальное решение для n элементов с ограничением по весу w. Это максимальное из следующих двух значений:

1. Оптимальное решение из (n-1) предметов с ограничением по весу w (без учета n-го предмета)
2. Значение n-го элемента плюс оптимальное решение из (n-1) элементов и w минус вес n-го элемента (включая n-й элемент)

Если вес n-го предмета больше текущего предела веса, мы его не включаем. Следовательно, он относится к первой категории из двух вышеуказанных случаев.

Мы можем реализовать эту формулу рекурсии в Java:

```java
public class Knapsack {
    public static int knapsackRec(int[] w, int[] v, int n, int W) {
        if (n <= 0) {
            return 0;
        } else if (w[n - 1] > W) {
            return knapsackRec(w, v, n - 1, W);
        } else {
            return Math.max(
                knapsackRec(w, v, n - 1, W),
                v[n - 1] + knapsackRec(w, v, n - 1, W - w[n - 1])
            );
        }
    }
}
```

На каждом шаге рекурсии нам нужно оценить два субоптимальных решения. Следовательно, время работы этого рекурсивного решения равно O(2^n).

### Пример использования

```java
int[] weights = {5, 6, 3};
int[] values = {10, 30, 15};
int capacity = 10;
int n = weights.length;

int maxValue = Knapsack.knapsackRec(weights, values, n, capacity);
System.out.println("Maximum value: " + maxValue); // Output: 40
```

## Решение с динамическим программированием

Динамическое программирование - это стратегия линеаризации экспоненциально сложных задач программирования. Идея состоит в том, чтобы хранить результаты подзадач, чтобы нам не пришлось пересчитывать их позже.

Мы также можем решить задачу о рюкзаке 0-1 с помощью динамического программирования. Чтобы использовать динамическое программирование, мы сначала создадим двумерную таблицу с размерностями от 0 до n и от 0 до W. Затем мы используем восходящий подход для расчета оптимального решения с помощью этой таблицы:

```java
public static int knapsackDP(int[] w, int[] v, int n, int W) {
    if (n <= 0 || W <= 0) {
        return 0;
    }
    
    int[][] m = new int[n + 1][W + 1];
    
    // Инициализация: для 0 предметов стоимость всегда 0
    for (int j = 0; j <= W; j++) {
        m[0][j] = 0;
    }
    
    // Заполнение таблицы
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= W; j++) {
            if (w[i - 1] > j) {
                // Предмет слишком тяжелый, не берем его
                m[i][j] = m[i - 1][j];
            } else {
                // Выбираем максимум: не брать предмет или взять его
                m[i][j] = Math.max(
                    m[i - 1][j],
                    m[i - 1][j - w[i - 1]] + v[i - 1]
                );
            }
        }
    }
    
    return m[n][W];
}
```

В этом решении у нас есть вложенный цикл по номеру элемента n и пределу веса W. Следовательно, время его работы составляет O(nW).

### Восстановление решения

Чтобы узнать, какие предметы были выбраны, мы можем пройти по таблице обратно:

```java
public static List<Integer> getSelectedItems(int[] w, int[] v, int n, int W, int[][] m) {
    List<Integer> selected = new ArrayList<>();
    int i = n;
    int j = W;
    
    while (i > 0 && j > 0) {
        if (m[i][j] != m[i - 1][j]) {
            // Предмет i был выбран
            selected.add(i - 1);
            j -= w[i - 1];
        }
        i--;
    }
    
    Collections.reverse(selected);
    return selected;
}
```

### Оптимизация памяти

Мы можем оптимизировать использование памяти, используя только одномерный массив:

```java
public static int knapsackDPOptimized(int[] w, int[] v, int n, int W) {
    if (n <= 0 || W <= 0) {
        return 0;
    }
    
    int[] dp = new int[W + 1];
    
    for (int i = 0; i < n; i++) {
        // Идем справа налево, чтобы не использовать уже обновленные значения
        for (int j = W; j >= w[i]; j--) {
            dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    
    return dp[W];
}
```

## Сравнение подходов

| Подход | Временная сложность | Пространственная сложность | Когда использовать |
|--------|---------------------|---------------------------|-------------------|
| Рекурсия | O(2^n) | O(n) | Маленькие задачи, для понимания |
| ДП (2D) | O(nW) | O(nW) | Стандартный подход |
| ДП (1D) | O(nW) | O(W) | Оптимизация памяти |

```kotlin
    for (i in 1..n) {
        for (j in 1..W) {
            if (w[i - 1] > j) {
                m[i][j] = m[i - 1][j]
            } else {
                m[i][j] = Math.max(
                    m[i - 1][j],
                    m[i - 1][j - w[i - 1]] + v[i - 1]
                )
            }
        }
    }
    
    return m[n][W]
}
```

### Оптимизированная версия (1D массив)

```kotlin
fun knapsackDPOptimizedK(w: IntArray, v: IntArray, n: Int, W: Int): Int {
    if (n <= 0 || W <= 0) {
        return 0
    }
    
    val dp = IntArray(W + 1)
    
    for (i in 0 until n) {
        for (j in W downTo w[i]) {
            dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i])
        }
    }
    
    return dp[W]
}
```

## Сложность

### Временная сложность

- **Рекурсивное решение:** O(2^n) - экспоненциальное время
- **Динамическое программирование:** O(nW) - псевдополиномиальное время

### Пространственная сложность

- **Рекурсивное решение:** O(n) - для стека вызовов
- **ДП (2D массив):** O(nW) - для таблицы
- **ДП (1D массив):** O(W) - оптимизированная версия

## Особенности

- **NP-трудная задача:** Не существует полиномиального алгоритма
- **Псевдополиномиальное решение:** ДП работает эффективно для небольших W
- **Оптимизация памяти:** Можно использовать одномерный массив

### Вариант 1: Неограниченный рюкзак

```java
public static int unboundedKnapsack(int[] w, int[] v, int n, int W) {
    int[] dp = new int[W + 1];
    
    for (int i = 0; i <= W; i++) {
        for (int j = 0; j < n; j++) {
            if (w[j] <= i) {
                dp[i] = Math.max(dp[i], dp[i - w[j]] + v[j]);
            }
        }
    }
    
    return dp[W];
}
```

### Вариант 2: Рюкзак с дробными предметами

```java
public static double fractionalKnapsack(int[] w, int[] v, int n, int W) {
    // Сортируем по соотношению стоимость/вес
    Item[] items = new Item[n];
    for (int i = 0; i < n; i++) {
        items[i] = new Item(w[i], v[i]);
    }
    Arrays.sort(items, (a, b) -> 
        Double.compare(b.ratio, a.ratio)
    );
    
    double totalValue = 0;
    int remainingWeight = W;
    
    for (Item item : items) {
        if (remainingWeight >= item.weight) {
            totalValue += item.value;
            remainingWeight -= item.weight;
        } else {
            totalValue += item.value * ((double) remainingWeight / item.weight);
            break;
        }
    }
    
    return totalValue;
}
```

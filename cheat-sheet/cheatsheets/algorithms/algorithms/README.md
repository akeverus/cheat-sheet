## Классификация алгоритмов

### По сложности

#### Линейные алгоритмы O(n)
```java
public void linearSearch(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            return i; // Найден элемент
        }
    }
    return -1; // Элемент не найден
}
```

#### Логарифмические алгоритмы O(log n)
```java
public int binarySearch(int[] arr, int target) {
    int left = 0;
    int right = arr.length - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (arr[mid] == target) {
            return mid; // Найден элемент
        } else if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1; // Элемент не найден
}
```

#### Квадратичные алгоритмы O(n²)
```java
public void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // Обмен элементов
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

### По подходу

#### Итеративные алгоритмы
```java
public int factorial(int n) {
    int result = 1;
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
}
```

#### Рекурсивные алгоритмы
```java
public int factorialRecursive(int n) {
    if (n <= 1) {
        return 1; // Базовый случай
    }
    return n * factorialRecursive(n - 1); // Рекурсивный случай
}
```

## Примеры алгоритмов

### Сортировка

- **Пузырьковая сортировка** — простой алгоритм, сравнивающий соседние элементы
- **Быстрая сортировка** — эффективный алгоритм с использованием опорного элемента
- **Сортировка слиянием** — стабильный алгоритм с использованием дополнительной памяти

### Поиск

- **Линейный поиск** — последовательный перебор элементов
- **Бинарный поиск** — поиск в отсортированном массиве
- **Интерполяционный поиск** — поиск на основе интерполяции

### Графовые алгоритмы

- **Поиск в ширину (BFS)** — обход графа по уровням
- **Поиск в глубину (DFS)** — рекурсивный обход графа
- **Алгоритм Дейкстры** — поиск кратчайшего пути

### Динамическое программирование

- **Последовательность Фибоначчи** — кэширование промежуточных результатов
- **Задача о рюкзаке** — оптимизация выбора элементов
- **Нахождение наибольшей общей подпоследовательности**

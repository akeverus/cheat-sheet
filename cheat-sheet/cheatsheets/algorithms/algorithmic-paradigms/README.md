## Введение в алгоритмические парадигмы

Алгоритмические парадигмы представляют собой фундаментальные подходы к решению вычислительных задач. Каждая парадигма имеет свои преимущества, недостатки и области применения.

```java
/**
 * Интерфейс демонстрирующий различные алгоритмические парадигмы
 * на примере задачи поиска максимального элемента в массиве
 */
public interface AlgorithmParadigm {

    /**
     * Полный перебор - проверяем каждый элемент
     * Временная сложность: O(n)
     * Преимущества: Простота, корректность
     * Недостатки: Медленно для больших данных
     */
    int findMaxBruteForce(int[] array);

    /**
     * Разделяй и властвуй - делим массив пополам
     * Временная сложность: O(n log n) для сортировки, O(log n) для поиска
     * Преимущества: Эффективность, масштабируемость
     */
    int findMaxDivideAndConquer(int[] array);

    /**
     * Динамическое программирование - запоминаем результаты
     * Временная сложность: O(n)
     * Преимущества: Оптимальность, эффективность
     */
    int findMaxDP(int[] array);
}
```

## Полный перебор (Brute Force)

Полный перебор - самый простой подход, при котором мы проверяем все возможные варианты решений.

### Принцип работы
1. Генерируем все возможные решения
2. Проверяем каждое решение на корректность
3. Выбираем лучшее решение

### Пример: Поиск максимального элемента

```java
public class BruteForceExample {

    /**
     * Поиск максимального элемента полным перебором
     * @param array входной массив
     * @return максимальный элемент
     */
    public static int findMaxBruteForce(int[] array) {
        // Проверяем входные данные
        if (array == null || array.length == 0) {
            throw new IllegalArgumentException("Массив не должен быть пустым");
        }

        int max = array[0]; // Предполагаем, что первый элемент максимальный

        // Проходим по всем элементам массива
        for (int i = 1; i < array.length; i++) {
            // Если текущий элемент больше максимального, обновляем максимум
            if (array[i] > max) {
                max = array[i];
            }
        }

        return max;
    }

    /**
     * Пример использования
     */
    public static void main(String[] args) {
        int[] numbers = {3, 7, 2, 9, 5, 1, 8};
        int max = findMaxBruteForce(numbers);
        System.out.println("Максимальный элемент: " + max); // Вывод: 9
    }
}
```

### Преимущества и недостатки
- **Преимущества**: Простота реализации, всегда находит правильный ответ
- **Недостатки**: Высокая временная сложность, неэффективен для больших задач

## Жадные алгоритмы (Greedy)

Жадные алгоритмы принимают локально оптимальные решения на каждом шаге в надежде получить глобально оптимальное решение.

### Принцип работы
1. На каждом шаге выбираем лучший доступный вариант
2. Не возвращаемся к предыдущим решениям
3. Продолжаем до достижения цели

### Пример: Задача о размене монет

```java
public class GreedyExample {

    /**
     * Жадный алгоритм для размена монет
     * Работает корректно только для канонических систем монет
     * @param amount сумма для размена
     * @param coins доступные номиналы монет (от большего к меньшему)
     * @return список монет для размена
     */
    public static List<Integer> coinChangeGreedy(int amount, int[] coins) {
        List<Integer> result = new ArrayList<>();

        // Сортируем монеты по убыванию (на всякий случай)
        Arrays.sort(coins);
        for (int i = coins.length - 1; i >= 0; i--) {
            int coin = coins[i];

            // Пока можем использовать эту монету
            while (amount >= coin) {
                result.add(coin);  // Добавляем монету в результат
                amount -= coin;    // Уменьшаем оставшуюся сумму
            }
        }

        // Если сумма не разменяна полностью, возвращаем пустой список
        return amount == 0 ? result : new ArrayList<>();
    }

    /**
     * Пример использования
     */
    public static void main(String[] args) {
        int[] coins = {1, 5, 10, 25}; // Американская система монет
        int amount = 67;

        List<Integer> change = coinChangeGreedy(amount, coins);
        System.out.println("Размен для " + amount + " центов: " + change);
        // Вывод: [25, 25, 10, 5, 1, 1]
    }
}
```

### Когда использовать жадные алгоритмы
- Задача имеет оптимальную подструктуру
- Локально оптимальные решения приводят к глобально оптимальному
- Задача не требует возврата к предыдущим решениям

## Разделяй и властвуй (Divide and Conquer)

Разделяй и властвуй разбивает задачу на меньшие подзадачи, решает их рекурсивно и комбинирует решения.

### Принцип работы
1. **Разделение**: Разбиваем задачу на меньшие подзадачи
2. **Решение**: Решаем подзадачи рекурсивно
3. **Комбинирование**: Объединяем решения подзадач

### Пример: Сортировка слиянием

```java
public class DivideAndConquerExample {

    /**
     * Сортировка слиянием - классический пример разделяй и властвуй
     * @param array массив для сортировки
     */
    public static void mergeSort(int[] array) {
        if (array.length < 2) {
            return; // Базовый случай: массив из 1 элемента уже отсортирован
        }

        int mid = array.length / 2;

        // Разделяем массив на две половины
        int[] left = Arrays.copyOfRange(array, 0, mid);
        int[] right = Arrays.copyOfRange(array, mid, array.length);

        // Рекурсивно сортируем каждую половину
        mergeSort(left);
        mergeSort(right);

        // Сливаем отсортированные половины
        merge(array, left, right);
    }

    /**
     * Слияние двух отсортированных массивов
     */
    private static void merge(int[] result, int[] left, int[] right) {
        int i = 0, j = 0, k = 0;

        // Пока есть элементы в обоих массивах
        while (i < left.length && j < right.length) {
            if (left[i] <= right[j]) {
                result[k++] = left[i++];  // Берем элемент из левого массива
            } else {
                result[k++] = right[j++]; // Берем элемент из правого массива
            }
        }

        // Копируем оставшиеся элементы
        while (i < left.length) {
            result[k++] = left[i++];
        }

        while (j < right.length) {
            result[k++] = right[j++];
        }
    }

    /**
     * Пример использования
     */
    public static void main(String[] args) {
        int[] numbers = {38, 27, 43, 3, 9, 82, 10};
        System.out.println("Исходный массив: " + Arrays.toString(numbers));

        mergeSort(numbers);
        System.out.println("Отсортированный массив: " + Arrays.toString(numbers));
    }
}
```

### Преимущества
- Естественная параллелизация
- Хорошая масштабируемость
- Эффективное использование памяти

## Динамическое программирование (Dynamic Programming)

Динамическое программирование решает сложные задачи путем разбиения их на простые подзадачи и запоминания решений.

### Принцип работы
1. **Оптимальная подструктура**: Решение задачи выражается через решения подзадач
2. **Перекрывающиеся подзадачи**: Одна и та же подзадача решается многократно
3. **Запоминание решений**: Храним результаты подзадач для повторного использования

### Пример: Задача о рюкзаке

```java
public class DynamicProgrammingExample {

    /**
     * Решение задачи о рюкзаке методом динамического программирования
     * @param weights веса предметов
     * @param values стоимости предметов
     * @param capacity вместимость рюкзака
     * @return максимальная стоимость
     */
    public static int knapsackDP(int[] weights, int[] values, int capacity) {
        int n = weights.length;

        // Создаем таблицу DP: dp[i][w] - максимальная стоимость
        // для первых i предметов и вместимости w
        int[][] dp = new int[n + 1][capacity + 1];

        // Заполняем таблицу
        for (int i = 1; i <= n; i++) {
            for (int w = 1; w <= capacity; w++) {
                if (weights[i-1] <= w) {
                    // Выбираем максимум из двух вариантов:
                    // 1. Не брать текущий предмет: dp[i-1][w]
                    // 2. Взять текущий предмет: values[i-1] + dp[i-1][w - weights[i-1]]
                    dp[i][w] = Math.max(
                        dp[i-1][w],  // Не берем предмет
                        values[i-1] + dp[i-1][w - weights[i-1]]  // Берем предмет
                    );
                } else {
                    // Предмет слишком тяжелый, не берем его
                    dp[i][w] = dp[i-1][w];
                }
            }
        }

        return dp[n][capacity];
    }

    /**
     * Пример использования
     */
    public static void main(String[] args) {
        int[] weights = {2, 3, 4, 5};     // Вес предметов
        int[] values = {3, 4, 5, 6};      // Стоимость предметов
        int capacity = 5;                  // Вместимость рюкзака

        int maxValue = knapsackDP(weights, values, capacity);
        System.out.println("Максимальная стоимость: " + maxValue); // Вывод: 7 (предметы 0 и 1)
    }
}
```

### Виды динамического программирования
- **Сверху вниз (Memoization)**: Рекурсивный подход с кэшированием
- **Снизу вверх (Tabulation)**: Итеративный подход с заполнением таблицы

## Поиск с возвратом (Backtracking)

Поиск с возвратом исследует все возможные решения, отсекая заведомо неправильные ветви.

### Принцип работы
1. **Выбор**: Выбираем следующий шаг решения
2. **Ограничения**: Проверяем, не нарушает ли выбор ограничения
3. **Цель**: Проверяем, не достигнута ли цель
4. **Возврат**: Если выбор неправильный, возвращаемся назад

### Пример: Задача о 8 ферзях

```java
public class BacktrackingExample {

    private static final int BOARD_SIZE = 8;

    /**
     * Решение задачи о 8 ферзях методом поиска с возвратом
     * @return количество решений
     */
    public static int solveNQueens() {
        int[] queens = new int[BOARD_SIZE]; // queens[i] - позиция ферзя в строке i
        return placeQueens(queens, 0);
    }

    /**
     * Рекурсивное размещение ферзей
     * @param queens массив позиций ферзей
     * @param row текущая строка
     * @return количество решений
     */
    private static int placeQueens(int[] queens, int row) {
        // Базовый случай: все ферзи размещены
        if (row == BOARD_SIZE) {
            printBoard(queens);
            return 1;
        }

        int solutions = 0;

        // Пробуем разместить ферзя в каждом столбце текущей строки
        for (int col = 0; col < BOARD_SIZE; col++) {
            if (isSafe(queens, row, col)) {
                queens[row] = col;  // Размещаем ферзя

                // Рекурсивно размещаем следующих ферзей
                solutions += placeQueens(queens, row + 1);

                // Возврат - ферзь будет заменен в следующей итерации
            }
        }

        return solutions;
    }

    /**
     * Проверка, безопасно ли размещать ферзя на позиции (row, col)
     */
    private static boolean isSafe(int[] queens, int row, int col) {
        // Проверяем все предыдущие строки
        for (int i = 0; i < row; i++) {
            // Проверяем вертикаль
            if (queens[i] == col) {
                return false;
            }

            // Проверяем диагонали
            if (Math.abs(queens[i] - col) == Math.abs(i - row)) {
                return false;
            }
        }

        return true;
    }

    /**
     * Вывод доски с ферзями
     */
    private static void printBoard(int[] queens) {
        System.out.println("Решение:");
        for (int i = 0; i < BOARD_SIZE; i++) {
            for (int j = 0; j < BOARD_SIZE; j++) {
                System.out.print(queens[i] == j ? "Q " : ". ");
            }
            System.out.println();
        }
        System.out.println();
    }

    /**
     * Пример использования
     */
    public static void main(String[] args) {
        int solutions = solveNQueens();
        System.out.println("Всего решений: " + solutions);
    }
}
```

## Методы ветвей и границ (Branch and Bound)

Методы ветвей и границ комбинируют поиск с возвратом с оценкой стоимости решений.

### Принцип работы
1. **Ветвление**: Разбиваем задачу на подзадачи
2. **Ограничение**: Отсекаем заведомо плохие решения
3. **Граница**: Используем оценки для отсечения

## Генетические алгоритмы (Genetic Algorithms)

Генетические алгоритмы имитируют естественный отбор для поиска оптимальных решений.

### Принцип работы
1. **Инициализация**: Создаем начальную популяцию решений
2. **Оценка**: Вычисляем приспособленность каждого решения
3. **Селекция**: Выбираем лучших особей
4. **Скрещивание**: Комбинируем решения
5. **Мутация**: Вносим случайные изменения
6. **Повторение**: Продолжаем до достижения критерия остановки

## Выбор парадигмы для задачи

### Критерии выбора парадигмы

| Парадигма | Когда использовать | Примеры задач |
|-----------|-------------------|----------------|
| Brute Force | Маленькие входные данные, простота важнее эффективности | Линейный поиск, простая сортировка |
| Greedy | Оптимальная подструктура, локальная оптимальность | Алгоритм Краскала, задача о размене монет |
| Divide & Conquer | Задача разбивается на независимые подзадачи | Сортировка слиянием, быстрая сортировка |
| Dynamic Programming | Перекрывающиеся подзадачи, оптимальная подструктура | Задача о рюкзаке, редакционное расстояние |
| Backtracking | Нужно исследовать все комбинации с отсечением | Задача о 8 ферзях, судоку |
| Branch & Bound | Комбинаторная оптимизация | Задача коммивояжера, целочисленное программирование |

### Советы по выбору парадигмы

1. **Начинайте с простого**: Brute Force для понимания задачи
2. **Анализируйте ограничения**: Размер входных данных, требуемая точность
3. **Тестируйте на крайних случаях**: Минимальные/максимальные входные данные
4. **Измеряйте производительность**: Время выполнения, использование памяти
5. **Комбинируйте парадигмы**: Часто оптимальное решение использует несколько подходов

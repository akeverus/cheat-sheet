# Паттерны проектирования

Шпаргалки по паттернам проектирования (Design Patterns).

## Структура

### 🏭 [Creational Patterns](creational/README.md) - Порождающие паттерны
- Singleton, Factory Method, Abstract Factory, Builder, Prototype

### 🏗️ [Structural Patterns](structural/README.md) - Структурные паттерны
- Adapter, Bridge, Composite, Decorator, Facade, Flyweight, Proxy

### 🏃 [Behavioral Patterns](behavioral/README.md) - Поведенческие паттерны
- Chain of Responsibility, Command, Interpreter, Iterator, Mediator
- Memento, Observer, State, Strategy, Template Method, Visitor

## Примечания

- Паттерны соответствуют классификации GoF(Gang of Four)
- Внутри разделов: описание, плюсы/минусы, пример кода, когда применять

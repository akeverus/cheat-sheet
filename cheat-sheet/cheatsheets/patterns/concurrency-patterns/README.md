# Паттерны конкурентности (Concurrency Patterns)

Паттерны конкурентности решают проблемы параллельного выполнения и синхронизации в многопоточных приложениях.

## Разделы

- [`active-object.md`](active-object.md) - Active Object (Активный объект)
- [`double-checked-locking.md`](double-checked-locking.md) - Double-Checked Locking (Двойная проверка блокировки)
- [`future-task.md`](future-task.md) - Future/Task (Будущее/Задача)
- [`producer-consumer.md`](producer-consumer.md) - Producer-Consumer (Производитель-Потребитель)
- [`read-write-lock.md`](read-write-lock.md) - Read-Write Lock (Блокировка чтения-записи)
- [`thread-pool.md`](thread-pool.md) - Thread Pool (Пул потоков)

Все паттерны конкурентности документированы и содержат подробные примеры на Java и Spring.

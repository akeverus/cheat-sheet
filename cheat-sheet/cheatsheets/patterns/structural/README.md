# Структурные паттерны (Structural Patterns)

Структурные паттерны объясняют, как собрать объекты и классы в более крупную структуру, сохраняя при этом гибкость и эффективность системы.

## Разделы

- [`proxy.md`](proxy.md) - Proxy (Прокси)
- [`decorator.md`](decorator.md) - Decorator (Декоратор) - Java
- [`adapter.md`](adapter.md) - Adapter (Адаптер)
- [`composite.md`](composite.md) - Composite (Композиция)
- [`facade.md`](facade.md) - Facade (Фасад)
- [`flyweight.md`](flyweight.md) - Flyweight (Легковес)
- [`decorator-kotlin.md`](decorator-kotlin.md) - Decorator (Декоратор) - Kotlin

Все структурные паттерны документированы и содержат подробные примеры на Java и Spring.

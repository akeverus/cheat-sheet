# Инфраструктура (Infrastructure)

**Комплексные руководства по инфраструктуре: Terraform, Ansible, Nginx, Packer, Vagrant, Consul**

## 📋 Описание

Этот раздел содержит детальные руководства по инструментам управления инфраструктурой: Infrastructure as Code (Terraform, Ansible, Pulumi), веб-серверы (Nginx), инструменты сборки образов (Packer), виртуализация (Vagrant), service discovery (Consul).

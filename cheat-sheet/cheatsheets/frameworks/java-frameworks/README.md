# Java Frameworks

**Enterprise фреймворки для Java: Spring, Micronaut, Quarkus, Vert.x, Dropwizard, Javalin**

## 📖 Рекомендуемый порядок изучения

### Для начинающих
```
1. Spring Boot
   ├── Spring Boot Basics
   ├── Spring MVC
   └── Spring Data JPA

2. Spring Security
   └── Authentication & Authorization

3. Spring Cloud Basics
   └── Microservices
```

### Для опытных
```
1. Выбор фреймворка
   ├── Spring → Enterprise, большая экосистема
   ├── Micronaut → Cloud Native, быстрый старт
   └── Quarkus → GraalVM, низкое потребление памяти

2. Продвинутые темы
   ├── Reactive Programming (WebFlux)
   ├── Microservices (Spring Cloud)
   └── Performance Tuning
```

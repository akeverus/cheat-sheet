## REF-001

- **ID:** REF-001
- **DATE:** 2026-08-22
- **OBJECTIVE:** Phase A — полный аудит текущего состояния фронтенда восемью параллельными направлениями (product-ux, ia-nav, visual-design, responsive, a11y-keyboard, tech-arch, assets-motion, history-decisions) и синтез в единый консолидированный документ с дедуплицированным бэклогом и STATE для Phase B.
- **PROBLEM:** Программа редизайна накопила 168 итераций и два расходящихся леджера (24_PROGRESS.md устарел на 108 итераций относительно frontend-redesign-state.md); скриншотный архив устарел на целую палитру (teal-эпоха при действующей «мастерской гильдии»); не существовало единой актуальной картины «что есть сейчас»: разрывы ядра цикла (optionless-тупик сессий, TRAINING без завершения), IA-долги (session-start под «Настройками», нерадресуемый вопрос), недотемизированный pixel-слой в light, мобильный фолд, 71% комментариев в CSS-корпусе и хвосты чистки ассетов были рассеяны по направлениям без приоритизации и дедупа.
- **EVIDENCE:** 144 сырых находки от 8 направлений аудита; все замеры — по живому приложению localhost:8080 (GET-only, обе темы, до 12 вьюпортов) и read-only SQL к живой БД; после дедупликации — 108 строк бэклога: 1×P0 (условный), 10×P1, 48×P2, 49×P3; плюс 26 позиций history-направления (14 инвариантов, 5 rejected/moot-решений, процессные грабли) вынесены в STATE.
- **DECISION:** Зафиксировать Phase A как завершённую; консолидировать находки в docs/frontend-refoundation-audit.md со строгой структурой (20 секций + сводный бэклог P0–P3 + STATE); дедуплицировать межнаправленные дубли (10 слияний, отмечены «также замечено»); противоречия между аудиторами (hero на главной vs REJECTED BASE-04; «невидимый» XP-флоатер vs мёртвый код) не решать молча, а зафиксировать в §15 как decision-gated; первым bottleneck выбрать UX-01 (optionless-тупик EXAM/MARATHON/STUDY) — единственный P0, детерминированная блокировка core-задачи, high confidence; квотные недоборы направлений зафиксировать честно (секция §152 с квотами в репозитории отсутствует — сверка по фактическим counts).
- **IMPLEMENTATION:** Созданы два файла: `docs/frontend-refoundation-audit.md` (шапка с источниками; секции 1–20: product model, visual language, IA, navigation, task model, responsive, components, tokens, pixel-art, motion, a11y, testing, strengths, weaknesses, contradictions, UX/visual/architecture debt, opportunities, redesign candidates; сводный бэклог 108 строк с ID-схемой UX-/IA-/VIS-/RSP-/A11Y-/ARCH-/AST-/HIST-; STATE с фазой, концептом, 14 инвариантами, rejected-списком, граблями, open problems, next bottleneck и квотами) и `docs/frontend-refoundation-changelog.md` (этот файл, запись REF-001).
- **TESTS:** n/a — итерация документационная, код и тесты не менялись.
- **VISUAL REVIEW:** По скриншотам прошлого цикла (work/redesign/artifacts) — ограниченно: весь архив снят в бирюзовой teal-эпохе и не соответствует действующему CSS «мастерской гильдии» (введён 2026-08-11); факт зафиксирован находкой VIS-11 (P2) с требованием переснять полный baseline (9 страниц × 2 темы × 3+ вьюпорта) первым шагом следующего цикла. Визуальные находки аудита опирались на свежие live-снимки аудиторов (обе темы, 1440/~500px и матрица до 2560), а не на устаревший архив; страницы result/session-summary визуально не покрыты (GET-only ограничение) — зафиксировано VIS-12.
- **ACCESSIBILITY:** Findings зафиксированы: 1×P1 (клавиатурная недоступность горизонтального скролла кода, WCAG 2.1.1), 3×P2 (угнанные хоткеи ↑/↓, потеря фокуса после оценки уверенности через native disabled, Space-раскрытие флешкарты), 5×P3 (недискаверабельная справка «?», h3 среди h2, мёртвые no-JS контролы, две цели вне ранговой системы, Esc без анонса) + межнаправленный дубль по pixel-motion-parity (нарушение контракта data-motion=on, слит в AST-08). Сильная a11y-база (0 безымянных контролов, скип-линки, tablist, #result-announce, inert-модалки) зафиксирована в strengths как инвариант.
- **REGRESSION:** Кода не касались — ни шаблоны, ни CSS/JS, ни Java не изменялись; незакоммиченная in-flight дельта print.css + session-summary.html (вероятно iter-169 прошлой программы) не тронута и защищена находкой HIST-03.
- **RESULT:** Backlog готов (108 дедуплицированных строк P0–P3 с evidence и предложениями); STATE заполнен (инварианты, rejected, грабли, квоты и недоборы); выбран первый bottleneck — **UX-01**: тупик вопросов без MCQ-вариантов внутри EXAM/MARATHON/STUDY (42/9818 вопросов в живой БД; первый шаг Phase B — живой POST-репро, затем фикс состава сессии либо POST-продвижение browse-блока + контракт-тест).

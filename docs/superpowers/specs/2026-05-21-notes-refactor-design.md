# Дизайн: рефакторинг заметок в SingularityApp

**Дата:** 2026-05-21
**Статус:** утверждён в брейнсторминге
**Scope:** 100 заметок из кеша (`mcp-singularity-listNotes-1779282748153.txt`)

## 1. Цель

Привести 100 пользовательских заметок к одному виду:
1. Удалить мусор (онбординг Сингулярити, устаревшее, дубли)
2. Структурировать (перенести неправильно расположенные)
3. Улучшить форматирование (Delta-bullets/заголовки/чек-листы)

НЕ архивируем выполненные планы (исторические записи остаются).

## 2. Архитектура

### Phase 0: Bulk-delete онбординг (1 confirm)
Автоматически фильтрую по фразам/URL (`singularity-app.ru`, «Рады», «Нажмите на иконку плюса», «Помодоро», «генеральная уборка» и т.п.). Показываю список → одно подтверждение → `deleteNote` оптом. Ожидаемо ~12-15 заметок.

### Phase 1: Per-note loop (~85 заметок)
Для каждой:
```
Title задачи: <title из task>
Content preview: <первые 200 символов плоского текста (Delta декодирован)>
[Keep] [Reformat] [Move] [Delete]
```

**Действия:**
- **Keep** — skip
- **Reformat** — генерирую улучшенный Delta (plain → bullets/заголовки/checked-lists где уместно), сразу `updateNote` без preview-confirm
- **Move** — second-question с 4 топ-релевантными проектами + Other; перенос через `updateTask(parent → new project)`
- **Delete** — `deleteNote`

**Порядок:** P- сначала (2 заметки), потом T- сгруппированы по проекту-родителю (Личное → Здоровье → Учёба → Работа → Хобби → Психология → Финансы); внутри проекта по дате модификации (свежее сверху).

### Phase 2: Summary + log
- В чат: счётчики по действиям
- Файл `docs/learning-plan/diagnostic/notes-refactor-log.csv` для аудита: `noteId,containerId,taskTitle,action,timestamp`

## 3. Границы

- Не подгружаем сверх 100 (max из последнего fetch)
- Не трогаем `removed=true` (корзина)
- Не дублируем подтверждение для Reformat (доверие Singularity undo)
- Phase A (Здоровье) идёт в общем потоке — не отдельным блоком

## 4. Риски и митигации

| Риск | Митигация |
|------|-----------|
| Reformat испортил заметку | CSV-лог с oldContent позволяет вручную откатить |
| Move попал в неправильный проект | Updates рядом с logged — найти и переместить ещё раз |
| Bulk-delete захватил что-то ценное | Перед удалением показываю список целиком — отказ возможен |
| 85 вопросов утомят | Принято пользователем; начать с легких категорий |

## 5. Out of scope

- Заметки, которых нет в текущем кеше (>100)
- Корзина (removed=true)
- Структурные изменения task'ов сами по себе (только перенос parent при Move)
- Создание новых заметок
- Pruning старых задач (только их note-контента)

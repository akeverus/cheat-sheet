# MCQ: проба процесса с полной редактурой одной темы

Действующий порядок: [workflow](workflow.md). Текст для LLM:
[промпт для целого файла](../../PROMPT_PLAN_INTERVIEW.md).

Передаём модели полный production JSON и Markdown одной темы, правила и
замечания. Она возвращает полный JSON и самостоятельно проверяет каждый блок.
Не запускаем скрипты, не выпускаем результаты частями, не создаём отдельные
отчёты о каждом проходе. Обозначаем `LLM_READY` только при полном охвате и без
существенного открытого замечания. Проверяем вкус и ясность на одном файле с
Сергеем до перехода к следующим темам. После замечаний уточняем общий промпт и
перегенерируем полный файл.

## Q25

| Вариант | Текущий видимый ответ | Полнота, истинность и попытка защиты |

| A | Корректность нарушается из-за чередования действий, например check-then-act; универсальная защита — перехватить ConcurrentModificationException, после чего состояние считается согласованным. | Определение плюс неверная универсальная защита.

## Оставшиеся конкретные находки

- Observability Q26:B.sections.if_it_were_true утверждает, что гарантированное сохранение всех ошибок является свойством tail-based. Это противоречит оговоркам correct A о полученных/поздних/вытесненных трассах; требуется отдельная содержательная правка с источниками, а не молчаливое изменение смысла при переводе.
- Java Concurrency Q32:B.how_it_should_be полностью английский: «Idle thief steals from busy worker's deque tail.»; Q24/Q31 и другие короткие пояснения тоже требуют редакции.
- Есть короткие английские примеры и списки в Application Security, Design Rate Limiter и Test Strategies. Подготовлены девять точечных переводов в четырёх наборах в mcq-russian-next-translation-candidates.json, DRAFT_NOT_APPLIED. Перед применением нужен полный пакет соответствующих Q/теории/A–D/sections; Java Q35 требует проверки того, что sync/async/parallel не обещают лишнего.
- В AI Compliance переведены восемь конкретных полей; остальные смешанные русско-английские фразы, а также исходные правовые/временные утверждения не получили FACTS PASS.
- Штатные ENGLISH_RUN-кандидаты сохранены в ru-corpus-english-signals.json; среди них есть код, диагностические литералы, официальные имена и ссылки. Общие части Markdown и комментарии к коду не объявлены вручную принятыми. Теорию редактирует параллельная задача.

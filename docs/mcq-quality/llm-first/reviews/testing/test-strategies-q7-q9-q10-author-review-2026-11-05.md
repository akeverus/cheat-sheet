## Q10

Что такое `Property-Based Testing`?

| Вариант | Видимый ответ | Полнота и проверка возможной защиты |
|---|---|---|
| A | PBT задаёт генератор допустимых входов; качество генератора позволяет считать результаты программы корректными без свойства, оракула или проверки поведения. | Полная ошибочная модель метода: качественная генерация объявлена достаточной для корректности. Даже полезная проверка отсутствия crash задаёт критерий и не доказывает любой нужный результат без него. |
| B | PBT задаёт свойство для допустимых входов и проверяет его на выбранных данных; найденный контрпример фреймворк может уменьшать, сохраняя нарушение свойства. | Ключ B: свойство, допустимый домен, конкретные проверенные входы и возможное упрощение контрпримера. Непроверенные значения не названы автоматически принятыми. |
| C | PBT проверяет свойство на выбранных входах; если нарушения не найдены, конечный прогон доказывает свойство на всём домене, включая непроверенные значения. | Полная модель с неверной гарантией: успешная конечная выборка объявлена доказательством также для непосещённых значений. Отдельный исчерпывающий конечный перебор не защищает это расширение. |
| D | PBT задаёт свойство и получает входы генератором; shrinking гарантирует наименьший из всех нарушающих входов, а ограничения поиска на эту гарантию не влияют. | Полная модель с неверной общей гарантией глобального минимума от shrinking. На частном простом домене минимум может быть найден, но это не общая гарантия независимо от ограничений поиска. |

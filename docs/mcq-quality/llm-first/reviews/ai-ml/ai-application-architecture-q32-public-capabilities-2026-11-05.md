## Проверенные границы источников

- [Notion Enterprise Search](https://www.notion.com/help/enterprise-search): доступен поиск workspace и подключённых приложений; scope и выбор модели влияют на источники. Это пример retrieval с ответом по данным, а физическая схема индекса — отдельный вопрос.
- [Cursor Search](https://cursor.com/docs/agent/tools/search) и [Agent](https://cursor.com/docs/agent/overview): текущий поиск использует Instant Grep без хранения embeddings кодовой базы для этого поиска; агент имеет инструменты работы с кодом. Это не утверждение об отсутствии embeddings или обучения во всех компонентах и исторических версиях Cursor.
- [Perplexity Pro Search](https://www.perplexity.ai/help-center/en/articles/10352903-what-is-pro-search): поиск, синтез и источники относятся к указанному режиму. [Agent API](https://docs.perplexity.ai/docs/agent-api/quickstart) отдельно документирует opt-in web search и запросы без цитат. Поэтому прежнее «online retrieval на каждый запрос» не сохранено. Само наличие ссылки ещё не доказывает поиск.
- [Devin Session Tools](https://docs.devin.ai/work-with-devin/devin-session-tools): рабочая сессия использует Shell/IDE/Browser и допускает вмешательство пользователя; Side Chat имеет отдельные ограничения. Из этого не выводится обязательная VM или остановка после каждого шага во всех продуктах Devin.

Страницы прочитаны 2026-11-05. Публичные функции используются как примеры паттернов; вывод о закрытых компонентах не делается. Нет запросов к платным API, запуска агентов или установки продуктов.

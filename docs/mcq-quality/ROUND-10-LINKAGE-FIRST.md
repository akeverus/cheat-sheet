# ROUND-10: переход к видимому вопросу

Историческая методология принята 2026-08-11. Действующие правила перенесены в
[единый стандарт](../mcq-quality-standard.md), процесс — в
[PROMPT_PLAN_INTERVIEW](../../PROMPT_PLAN_INTERVIEW.md).
Этот файл сохраняет совместимость существующих ссылок, а не отдельный канон.

Ключевой результат раунда: `question_text` JSON не виден пользователю;
варианты связываются с вопросом Markdown через topic/category и q_number.
Связь L3/L4 должна подтверждаться по видимому Q и его теории, а не по скрытому stem.
Это защищает `McqVisibleLinkageContractTest`.

При консолидации сохранены в стандарте:
- приоритет фактов и проверка всех трёх wrong по материалу Q;
- разделение лексического скана и содержательного доказательства;
- повторная проверка зависимых sections после правки источника/варианта;
- проверка кода и версии по первоисточнику;
- самостоятельная проверка формы и фактов;
- ограниченный цикл ремонта, привязка доказательств к содержимому и honest NOT_RUN.

Исторические baseline, рассказы о волнах, команды reset и требования бесконечных
«чистых кругов» исключены из действующей инструкции. Результаты отдельных тем
сохранены в review-sidecars и linkage-reset-manifest; их применимость проверяется
по [audit-state.json](audit-state.json). Старые версии методологии доступны в Git.

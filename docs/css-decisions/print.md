# print.css — досье решений (ARCH-02)

Полные доводы и история правил, вынесенные из комментариев `print.css`
(REF-009): эссе читают при ПЕРЕСМОТРЕ решения, а не при каждом чтении файла.
У правила в CSS остаётся указатель с тезисом; якоря ниже — цель указателей.
Рабочие инварианты («НЕ менять», пороги) остаются в CSS.

## print-e01 · print.css:33

**Контекст:** `html[data-design] .focus-aside.focus-session-rail,`

Страница вопроса (фокус): интерактивный хром на бумаге бессмыслен — рельс
     сессии (прогресс/стрик/«Завершить»), подсказка «как отвечать», submit-футер
     с таймером, клавиатурная подсказка, reveal/оценочные формы флешкарты,
     кнопка-summary «Пример кода» (открытый <details> печатает код и без неё),
     пост-ответные кнопки (уверенность, «Похожие вопросы») и CTA пустого
     состояния. Сам вопрос, радио-варианты и вердикт #result-feedback остаются —
     печать вопроса для офлайн-разбора.

     Строка идентичности (.focus-topbar) на бумаге ОСТАЁТСЯ: тема и сложность
     отвечают «откуда этот вопрос», а на распечатке без навигации это
     единственный источник контекста. Раньше её прятали заодно с рельсом сессии —
     под комментарием «топбар сессии», хотя сессия жила в другом элементе, и он-то
     как раз печатался.

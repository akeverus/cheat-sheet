## Обязательный шаг воркфлоу после `apply2.py`

`apply2.py` правит только заголовки `## Q<N>`. Если в патче были записи `mdhead`, сразу после
применения обязателен прогон:

```
python3 scripts/readability/regen_toc.py cheatsheets/interview/<category>/<topic>-interview.md
```

и проверка `heads == toc` по тексту. Без него блок `## Содержание` остаётся с прежними
формулировками и битыми якорями (X-003).

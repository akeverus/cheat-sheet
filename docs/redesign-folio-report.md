# FOLIO — итоговый отчёт тотального визуального редизайна

Директива: `MASTER_MISSION_TOTAL_PRODUCT_VISUAL_REDESIGN.md` (2026-08-29).
Формат каждой крупной области: **BEFORE → CHANGE → AFTER → VALIDATION** (§122 миссии).
Коммиты кампании: `574a9fca` → `b56bf4c6` → `265f3630` → `b82f11b4` → `82aa5406` (+ доки/чистка финальным коммитом).

## 1–3. Старый дизайн, новый дизайн, почему старый отвергнут

**BEFORE.** «Modern Medieval / гильдейская мастерская»: тёмная тема = чёрно-коричневый
камень #14120f + латунь #d0a33c, светлая = пергамент #ece4d3 + охра; pixel-art слой на
весь продукт (9 CSS-файлов ~76KB: жёсткие offset-тени кнопок, rect-спрайт иконок 16×16,
PNG-стикеры разделов, гербы гильдии, конфетти/rainbow-анимации, зерно холста,
corner-маски), радиус 0 повсюду, mono-uppercase ярлыки на каждом блоке, RPG-обрамление
прогрессии («путь гильдии»).

**WHY REJECTED.** Обе палитры — буквально паттерны, запрещённые миссией §9
(«dark = black + gold», «light = beige + brown»). Pixel-иконка на каждой кнопке —
прямой запрет §41. Рамка на каждом элементе — «excessive borders» §90; squint-тест
давал равномерный коричнево-золотой тон. Костюм конкурировал с контентом и читался
как game HUD, а не как premium developer tool (§92).

**CHANGE → AFTER.** Направление **FOLIO «графит и чернила»** — contemporary editorial
knowledge workspace (Direction B из трёх, §7): продукт про чтение и мышление.
Из трёх направлений (A «Developer Learning OS» — template-риск Linear-клона;
B editorial; C sans-only pro tool — теряет фирменный серифный вопрос) выбрано B:
единственное с сильной собственной идентичностью, опирающейся на уже фирменный
актив продукта — серифный display вопроса.

**VALIDATION.** Pinned-тест `tokensCssDefinesSingleFolioDesign` держит новую палитру и
блок-лист всех трёх снятых направлений (терминал-teal, латунь/пергамент, warm-editorial).

## 4–5. Art direction и дизайн-система

- **Цвет**: dark = холодный графит `#141518`, поверхности светлотой
  (`#1e2025`/`#24262c`), кобальт `#366fc5` (единственный акцент, белая надпись);
  light = бумага `#f9f8f6` + белый лист + чернила `#1b1d21`, кобальт `#155ab2`.
  Полный статус-спектр (success/warning/error/info/purple + -wash), отдельные
  `--code-*` для подсветки. Обе темы спроектированы парой; контраст-аудит
  `scripts/design-token-audit.py`: **46 пар — CLEAN** (0 hard-fail, 0 large-warn).
- **Типографика**: три голоса с жёсткими ролями — Literata только display
  (вопрос, заголовки страниц, крупные числа), Inter — весь UI включая
  эйбрау-ярлыки (были mono-caps, переведено 45 правил), JetBrains Mono — только
  код, клавиши, табличные цифры/таймеры. Текучая шкала заголовков сохранена
  (HeadingScaleContractTest).
- **Форма**: радиус-шкала `xs2 / sm4 / md8 / lg12 / xl16 / full999` вместо
  тотального нуля; литеральные радиусы запрещены гейтом (SurfaceLanguageContractTest).
- **Поверхности**: иерархия светлотой + волосок `border-secondary` у карточек
  (в светлой теме без него белый лист исчезает на бумаге); рамка остаётся
  признаком контрола (WCAG 1.4.11, `--color-control-border` в обеих темах).
- **Иконки**: Lucide (ISC), 24×24, stroke=currentColor; два спрайта
  (`.ui-icon` интерфейс / `.ui-illus` глифы состояний), генератор
  `scripts/gen-icon-sprite.py`; бренд `#crest` (книга с закладкой) = favicon.
- **Motion**: токены длительностей/изингов сохранены; сняты все декоративные
  циклы pixel-эры (arrowNudge/rainbow/confetti/optionPop); спиннер ожидания —
  плавное кольцо; reduced-motion гасит всё (e2e-страж на 7 поверхностях,
  включая контроль применимости эмуляции).

## 6–7. Навигация и shell

**KEPT (осознанно).** Одна навигация-сайдбар с 5 разделами, mobile bottom-nav,
единственный тоггл темы — структура прошла сотни итераций с замерами и
контрактами (NavigationSource/ShellChrome), миссия требовала пересмотра, не
слома: пересмотр дал «сохранить структуру, заменить кожу». Новое: кобальтовая
активная пилюля, Lucide-иконки, бренд-плитка (кобальт + белый знак книги).
Command palette (§49) — рассмотрена и **отклонена**: 5 разделов, поиск на
topics/bookmarks, полный клавиатурный контур (1-4/стрелки/Esc/Enter/«?»);
новая JS-подсистема не окупается.

## 8–9. Question workspace и режимы

Композиции всех 8 режимов (mode-specific workspaces, контракты ModeWorkspace/
RecallComposition/StudyReading) сохранены — они и были спроектированы под разные
cognitive tasks (§6 миссии). Перекрашено и дочищено: MCQ-опции — строки с
letter-чипами (выбор = кобальтовая рамка+wash; верно/неверно = статусные семьи +
словесные ярлыки, не только цвет); armed-сабмит стал полноценным primary;
пост-ответная трансформация (вердикт → XP → SM-2 → уверенность → вкладки разбора)
работает в обеих темах и в no-JS (`result.html` проверен серверным POST).

## 10–13. Analytics, Topics, Settings, Summary

- `/stats`: иерархия «Что делать дальше» → «Где я сейчас» → KPI → графики →
  детализация; серифные numerals; лестница уровней без «гильдии» (знаки ступеней
  Lucide: sprout→…→graduation-cap); графики лениво и в палитре продукта.
- `/topics`: строки разделов ужаты (24→16px вертикали, заголовок на шкале
  minor) — каталог сканируется одним экраном; знаки разделов — кобальтовые
  плашки Lucide вместо PNG-стикеров.
- `/settings`: сегментные контролы с кобальтовым selected; ось «пиксельность»
  снята из пресетов (осталось density + reading-width); межпанельные поля ужаты.
- `/session-summary`: кольцо счёта, KPI-плитки, лестница, разбор ошибок,
  печать-сцена тонкой линией — проверено живой сессией (экзамен → досрочное
  завершение с confirm-модалкой → итоги).

## 14–18. Mobile / macOS / ultrawide / темы

- Mobile 390: рекомпозиция (статус-строка вместо колонки показателей, fixed-док
  сабмита над bottom-nav, компакт resume-баннера); заголовок вопроса на 378px —
  выше сгиба даже с баннером.
- macOS/WebKit: **обязательный гейт пройден** — весь e2e (клавиатура, консоль,
  reflow 320px + зум-ширины 1152/1382/1571, шрифт-сеть, reduced-motion,
  визуальная матрица) гоняется в WebKit наравне с Chromium; голдены разведены
  по движкам.
- Ultrawide 2560: трёхколоночный воркспейс (вопрос+код / опции / бриф темы),
  мёртвого центра нет; ширина композиции считается из мер собственных колонок.
- Темы: dark — дефолт, light — самостоятельная система (не инверсия);
  визуальная матрица кроет обе.

## 19–20. Accessibility и motion

Сохранены и перепроверены: skip-link, фокус-идиома «outline 2px наружу» на всех
рангах, focus-ring токен в обеих темах, WCAG 1.4.1 (смысл не только цветом:
словесные ярлыки вердиктов/статусов), 1.4.11 (рамки контролов ≥3:1), тач-цели
44px (24px минимум нигде не нарушен), reflow без горизонтали на 320px, консоль
чиста на всех поверхностях. Reduced-motion: CSS-медиа + JS-ось + e2e-страж.

## 21. Performance

Архитектура доставки не менялась (одна CSS-лента на страницу + content-hash,
modulepreload-манифест, mermaid/chart по видимости). Редизайн её облегчил:
−76KB pixel-CSS, −10 PNG-стикеров, −3.4KB pixel-icons.svg; бандл фокуса
~58KB (было ~94KB сырых). Никакого backdrop-filter/particles/canvas-декора.

## 22–23. CSS/JS архитектура

`@layer tokens → reset → shell → components → pages → utilities` (слой pixel
удалён из порядка); краска компонентов вернулась из декоративного слоя в
components-* (кнопки: скелет+ранги+состояния в одном файле; вкладки;
спиннер). JS: переименования классов (`px-icon→ui-icon`, `px-illus→ui-illus`),
удалён мёртвый декоративный код; манифесты целы (двусторонние тесты).

## 24. Backend changes

Минимальные и только именные: `RankUtils.glyph()` → id `rank-*`;
`topic-groups.yaml` — id символов вместо путей к PNG; лексика прогрессии без
«гильдии». Домен, флоу, scoring, persistence — не тронуты (§83).

## 25–27. Удалённое наследие и ассеты

Удалены: 9 `pixel-*.css`, спрайты-«гербы», PNG-стикеры + генератор,
`static/img/**` целиком, `static/icons/pixel-icons.svg`, ось `data-pixel`,
рампы `--pixel-*`/`--px-*`, осиротевший `scripts/normalize-pixel-palette.py`,
рудимент `data-pixel-icon`. Лицензии: шрифты OFL (self-hosted, только
unicode-range-сабсеты), иконография Lucide ISC (реестр — `docs/visual-assets.md`).
Растровых ассетов в продукте: **0**.

## 30. Adversarial review

Первый проход (§102) — по ходу кампании: найдены и исправлены битые состояния
после сноса слоя (armed-сабмит без краски, невидимый бренд-знак, беззащитные
эмблемы/сцены с fill-идиомой, чёрные блоки mode-глифов), плотность каталога,
терминальный голос ярлыков. Второй независимый проход (§104) — семь линз
(иерархия dark/light 1440, mobile 390, wide 1920, консистентность, остатки эры
в коде, a11y) по свежей матрице из 27 скриншотов; 47 находок medium+
верифицированы построчно против кода и задокументированных решений.
**Подтверждено и исправлено:** потерянная со слоем краска выбранной самооценки
(.confidence-btn/.flashcard-grade-btn .selected), красный ховер «Убрать»
закладку, фокус навигации переведён с box-shadow на общую outline-идиому
(переживает forced-colors), active в mobile-nav получил второй признак (вес),
полоса «Дневная цель» стала читать --progress (была всегда полной), трек
освоения каталога тем стал видимым метром (был волосок-основание), инлайн-код
в вариантах не рвётся внутри чипа, «Отбросить» в баннере поднят до читаемого
secondary с полным порогом касания, сегмент «Большой монитор» → «Монитор»,
лид конструктора не пересказывает раскладку (хвост снят вместе с клип-правилом
и контрактом), дюжина комментариев о pixel-слое в настоящем времени переведена
в прошедшее, удалены осиротевшие scripts/normalize-pixel-palette.py и атрибут
data-pixel-icon. **Опровергнуто:** четыре «битых var()» (токены-призраки — в
исходниках нулевые вхождения), переносы Literata (документированные русские
переносы hyphens:auto), «перекрытие контента» закреплёнными панелями
(задокументированные гарантии FRD-008/009), резерв строк заголовка вопроса.
Low-заметки (15) зафиксированы в журнале воркфлоу как бэклог вкуса.

## 31. Известные оставшиеся ограничения

- `/login` — живёт только в multi-режиме (выключен); шаблон на токенах,
  живой проверки в local-режиме нет по построению.
- Незавершённая сессия пользователя (1/50) была заменена e2e-прогоном полного
  цикла — цена обязательного §100.
- Названия ступеней («Ученик…Магистр») сохранены как лестница мастерства —
  осознанное решение (§42: progression как subtle DNA); класс `GuildRank` —
  внутреннее имя, пользователю не видно.
- `docs/design-system.md` местами описывает компоненты глубже, чем требует
  повседневная работа; сведение дублей с `frontend-architecture.md` — отдельная
  документационная задача вне визуальной миссии.

# Релейаут: «широкая колонка + верхний бар»

Дата: 2026-06-16. Триггер — прямая претензия пользователя: взаимное расположение
блоков на страницах выглядит любительски («как будто только учишься верстать —
очень хуёво»), особенно на home/focus.

## Выбранное направление

После показа трёх ASCII-превью пользователь выбрал **«Широкая колонка + верх.
бар»**:

- одна полноширинная колонка край-в-край (без правой колонки-сироты);
- сверху горизонтальный мета-бар: eyebrow/подсказка слева ↔ статус сессии /
  «сегодня» справа;
- вопрос на всю ширину;
- варианты ответа — сеткой 2×2 (экзаменационный бланк).

## Что было не так (focus / home)

`.focus-training` рендерился как 2-col grid `minmax(0,1fr) 19rem`: основная
колонка ~941px + правая sticky-рейка 304px. **Вне сессии** рейка вырождалась в
одинокий «сегодня»-чип высотой ~54px в мёртвом правом жёлобе — это и читалось
как любительская вёрстка. (BEFORE: `relayout-home-1440-dark-BEFORE.png`.)

## Реализация (focus)

Коммит `3cb0c4e9`. Файлы: `focus-training.html`, `editorial.css` (v77→v78),
`fragments/head.html`.

- eyebrow (`.question-zone-head`) + рейка (`.focus-session-rail`) обёрнуты в
  новый `.focus-topbar`.
- `@media (min-width:1200px)`: `.focus-topbar` — flex `space-between` с
  hairline-разделителем снизу; рейка стала горизонтальным кластером
  (прогресс «N/total» + трек 8rem + «сегодня»-чип + «Завершить сессию»).
- `#interview-options` — сетка 2×2 уже с 1200px (раньше только с 1680px → на
  1200–1680 справа зияла мёртвая зона). Буквенный CSS-счётчик и клавиши 1–9 не
  затронуты.
- После ответа `#interview-options:has(.option-explanation)` возвращает одну
  колонку с капом 60rem: раскрытые объяснения удобнее читать вертикальным
  сканом (как на /answer), а не сравнивать в 2×2 с рваными по высоте ячейками.
- Ниже 1200px без изменений — обычный вертикальный стек; удалён ставший
  избыточным `@media 1680px`.

Live-проверено (chrome-devtools, 1440px, dark+light): нет-сессии, активная
сессия, до/после ответа — все состояния чистые, консоль без ошибок.
Скрины: `relayout-home-1440-{dark,light}-AFTER.png`, `relayout-home-session-dark.png`,
`relayout-home-answered-1col-options-dark.png`.

## Аудит остальных контент-страниц

Дефекта «колонка-сирота / мёртвый жёлоб» уровня focus на других страницах НЕТ —
они уже получили осознанную широкую раскладку в прошлых волнах редизайна:

- **/settings** (`relayout-settings-1440-dark.png`): hero «СЕГОДНЯ … → Начать
  повторение» = верхний бар; ниже 3-col панель управления (Фильтры | Сессия |
  Прогресс) + 2-col (Управление данными | Персонализация). Минор: «Сессия»
  короче соседних колонок → немного запертого whitespace под кнопкой.
- **/stats** (`relayout-stats-1440-dark.png`): дашборд — Фильтры | Поиск,
  6-карточный KPI-ряд, два графика, Детализация (2fr) | Прогноз (1fr). Минор:
  карточка прогноза короче таблицы → пустой правый нижний жёлоб.
- **/session-summary** (`relayout-summary-1440-dark.png`): hero-лента (режим +
  % ↔ карточки ВСЕГО/ВЕРНО/ОШИБКИ ↔ время), ниже 2-col (Результаты | Ошибки) +
  «Рекомендации». Минор: рекомендации занимают только левую колонку.
- **result.html** — no-JS фолбэк /answer; при включённом JS пользователь видит
  инлайн-разбор на focus-странице (уже редизайнут). Низкий приоритет.

**Вывод:** focus был единственной страницей с грубым дефектом расположения.
Остальные — связные дашборды; оставшиеся минусы — типовой неровный whitespace в
2-col секциях (кандидаты на тонкий полиш, не «любительская вёрстка»).

## Изменения

- Q1 различает семейство heap и полную бинарную форму binary heap; inorder
  не гарантирует сортировку. Удалён неподтверждённый перечень системных
  планировщиков, включая Linux CFS. Документация ядра описывает для CFS
  time-ordered rbtree, поэтому CFS нельзя приводить как пример binary heap.
- Q25 разделяет число задач N, cooldown n и число типов u. Код больше
  не перебирает idle ticks: прибавляет полное окно, если осталась работа,
  либо только выполненные задачи последнего окна. long защищает длину
  расписания при больших cooldown. Указана стоимость O(N log(u+1)+26),
  фиксированная память O(26), пустой вход, n=0 и границы результата.
  Код вычисляет длину, не восстанавливает последовательность букв.

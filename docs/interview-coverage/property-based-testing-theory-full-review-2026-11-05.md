## Источники

Сверялась документация **Hypothesis 6.170.14**: [strategies](https://hypothesis.readthedocs.io/en/latest/reference/strategies.html) для constant/composition/regex; [API](https://hypothesis.readthedocs.io/en/latest/reference/api.html) для backend cache и фаз; [stateful guide](https://hypothesis.readthedocs.io/en/latest/stateful.html) для rules, preconditions, invariants и TestCase. Для Java использовалось [руководство jqwik 1.9.3](https://jqwik.net/docs/1.9.3/user-guide.html): отдельный engine, constraints, provider, lifecycle property/try и @Example. Для JS — [fast-check Getting Started](https://fast-check.dev/docs/introduction/getting-started/), страница с отметкой обновления 2026-08-18: роли property/assert и asyncProperty. Версия локального fast-check не установлена и не выдумывалась.

Историческая ссылка Q8 ограничена метаданными и аннотацией оригинальной статьи [Claessen/Hughes, ICFP 2000, DOI](https://dl.acm.org/doi/10.1145/351240.351266), доступными в выдаче первичного издателя.

## Исправления и согласование

- **Q7:** optional parent у root, root не обязательно HTTP, links в том числе между traces. Убраны гарантии полного пути и немедленного определения причины по длительности. Схема показывает отношения; перекрывающиеся интервалы нельзя складывать. Согласовано с Q5 и MCQ Q7 A. [OTel traces](https://opentelemetry.io/docs/concepts/signals/traces/).
- **Q8:** невалидное wire-значение в Mermaid заменено ссылкой на единый валидный пример version 00; описаны remote parent и собственный ID нового span, ненулевые lowercase hex IDs, optional tracestate и отсутствие гарантии хранения от sampled. Автоматическая propagation ограничена подключённой инструментацией и поддерживаемыми клиентами; приведены builders Boot 3.3. Значение sampling — пример политики. Согласовано с Q8 D. [W3C](https://www.w3.org/TR/trace-context/), [Boot tracing 3.3](https://docs.spring.io/spring-boot/3.3/reference/actuator/tracing.html).
- **Q10:** версия Boot 3.3, dependency management, registry/binders/endpoint разделены; `sla` заменено на `slo`. Удалён неполный OrderController с необъявленным orderService. Оставлен короткий TimedAspect config с imports и условиями Spring AOP; self-invocation не обещает измерения. Согласовано с Q10 C. [Boot metrics 3.3](https://docs.spring.io/spring-boot/3.3/reference/actuator/metrics.html), [Micrometer Timers](https://docs.micrometer.io/micrometer/reference/concepts/timers.html).
- **Q11:** ошибочный Java-пример «экспоненциальной гистограммы» заменён scale/base и положительными интервалами OTel. Micrometer percentile histogram и expected range не выданы за выбор ExponentialHistogram/native. Убрана гарантия экспозиции такого типа Timer по умолчанию. Согласовано с Q11 D. [OTel data model](https://opentelemetry.io/docs/specs/otel/metrics/data-model/#exponentialhistogram), [Micrometer histograms](https://docs.micrometer.io/micrometer/reference/concepts/histogram-quantiles.html).
- **Q12:** binder отделён от HTTP; deadlock alert убран из гарантированных default. Проверен конкретный JvmThreadMetrics 1.13.2. Большой непроверенный Grafana JSON заменён таблицей единиц и примерами PromQL: pool scope и положительный max, средняя GC за окно и ненулевой count. Байтовые метрики не сравниваются с долевыми порогами 0.8/0.9. Согласовано с Q12 C. [JvmThreadMetrics v1.13.2](https://raw.githubusercontent.com/micrometer-metrics/micrometer/v1.13.2/micrometer-core/src/main/java/io/micrometer/core/instrument/binder/jvm/JvmThreadMetrics.java).
- **Дополнение Q12 из проверки:** JvmGcMetrics 1.13.2 регистрирует `jvm.gc.pause` в обработчике уведомления. Отсутствие ряда до подходящего события не равно нулевой паузе. Это согласуется с уже имеющимся MCQ Q12 C.edge_cases об отсутствии series. [JvmGcMetrics v1.13.2](https://raw.githubusercontent.com/micrometer-metrics/micrometer/v1.13.2/micrometer-core/src/main/java/io/micrometer/core/instrument/binder/jvm/JvmGcMetrics.java).
- **Q13:** существующий `.register(registry)` сохранён. Уточнены достижимость источника gauge, дискретность наблюдения, монотонность FunctionCounter и ограничение переменной части имени operation вместе с tags. Конечные labels требуют бюджета сочетаний. Комментарий и имя фабрики Timer приведены к SLO. Согласовано с Q13 A. [Gauges](https://docs.micrometer.io/micrometer/reference/concepts/gauges.html), [Counters](https://docs.micrometer.io/micrometer/reference/concepts/counters.html).

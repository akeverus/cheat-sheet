## Вопросы и варианты

Видимые Markdown-заголовки сохранены. Для каждого wrong проверялась возможность
защитить его при данных условиях, а не только наличие ложного тезиса.
Полнота ложной модели оценивается отдельно от её истинности.

Раскрытый LLM-разбор отдельно рассмотрел CONTENT, FACTS, LINKAGE, SECTIONS,
SFPL, ANSC и RU. Для семи блоков не найдено неполных видимых вариантов или
защитимых wrong в принятой таксономии. Эти локальные выводы не зарегистрированы
как независимая приёмка. Фактические длины и поопционные основания сохранены
в raw-отчётах. Рецензенты явно запущены с `model=gpt-6-luna`,
`reasoning_effort=medium`, `fork_turns=none`; их оговорка об отсутствии
самостоятельного доступа к runtime identity сохранена без исправления.

**Открытый дефект MCQ Q8B, SECTIONS — FAIL.** Секция `if_it_were_true`
утверждает: приёмочные тесты после реализации «только описывали бы уже
реализованное поведение». Это не следует из варианта: такие тесты могут
выражать ожидаемые требования, обнаруживать расхождения и направлять
последующие исправления. Они лишь не направляли первоначальную реализацию
test-first. Первый вторичный обзор пропустил ошибку; после точечного возражения
отдельный follow-up признал дефект. Оба результата сохранены, исходный PASS
задним числом не переписан. Предлагаемая замена секции:

> Тесты, созданные после первоначальной реализации, не направляли бы её
> test-first; они всё ещё могли бы выявить расхождение с ожиданиями и направить
> последующие исправления. Поэтому такой подход сам по себе не является ATDD
> для этой реализации.

Production JSON не изменялся этим автором. Исправление и повторная проверка
четырёх вариантов/sections Q8 остаются владельцу MCQ.

## Проверки и границы

- **Runtime Q41: 5/5 PASS**, JDK 21.0.10, Mockito 5.11.0, JUnit 5.10.3.
  Три Java-фрагмента извлечены из Markdown. Fake скомпилирован без изменения;
  неполные фрагменты Mockito помещены в явно сохранённые минимальные fixtures

  уведомление, отсутствующий ID, хранение разных ID, обновление ID и отсутствие
  вызова реального метода при настройке `doReturn`. Это пять тестов, а не семь
  отдельных тестов по числу перечисленных наблюдений.

  runtime и приложения с broker/фикстурами. Примеры сверены с документацией;
  компиляция против искусственных заменителей библиотек не использовалась.
- **Mermaid renderer: NOT_RUN.** Положения квадрантов сверены с официальной
  документацией; визуальная приёмка диаграмм не заявляется.
- Schema/structure PASS: 45 Q, 45 блоков, 180 опций; 45 ссылок оглавления,
  последовательные и неизменные заголовки, существующие относительные ссылки.
  Префикс, включая YAML, побайтово сохранён; отдельный YAML parser недоступен.
  `verify-md-no-mcq` и `git diff --check` PASS.
- Linkage до/после: **0 errors / 3 warnings**. Предупреждения Q23C, Q30

# Mutation Testing: StrykerJS и CI, Q12/Q20

Исправлены только тела теории Q12/Q20. Пролог, остальные 18 тел, ID/заголовки, метаданные, оглавление и See also сохранены. Production MCQ JSON не менялся. Рассмотрены восемь текущих опций и 34 поля пояснений. Общей приёмки темы нет.

Q12 теперь описывает именно StrykerJS, отдельно от других продуктов семейства. Даны подготовка Node/npm и тестов, инициализация по официальному сценарию, проверка конфигурации, testRunner/mutate, запуск и чтение отчёта. Настройки thresholds вынесены отдельно: high/low — цвета, score строго ниже break — exit code 1, break:null отключает только score-отказ. Пример 49/50/51 при break 50 ограничен данным условием; прочие ошибки могут дать ненулевой код. Убрано неподтверждённое ранжирование тренда над абсолютным порогом.

Q20 теперь предлагает CI-политику по времени и риску, а не обязательные nightly/changed-files-only. Различены область, история и повторное исполнение всех мутаций. Раскрыты сохранение incremental JSON для StrykerJS, обязательный исходный dry run, ограничения обнаружения тестовых/внешних изменений, force только внутри области, PIT history и особенности временного каталога/явных путей. Отчётность, score-gate и обработка ошибок разделены; универсальные 60% и неподтверждённые заявления о распространённости/компаниях удалены.

## Исправления

**Q14:** exemplar связан с отдельным наблюдением; p99 — оценка квантиля за окно. Убрано обещание найти «именно тот trace», породивший p99/причину всплеска. В минимальном provisioning указаны явные UID, а имя trace label отмечено примером, который надо сверить с данными. Trace ID exemplar не становится обычным label ряда. Exemplar/trace могут отсутствовать из-за sampling/доставки/retention; лог-корреляция настраивается отдельно. Согласовано с MCQ Q14 D. [Grafana exemplars](https://grafana.com/docs/grafana/latest/fundamentals/exemplars/), [datasource config](https://grafana.com/docs/grafana/latest/datasources/prometheus/configure/).

**Q15:** удалены универсальные рейтинги backend и обещание сменить любой backend одним URL. Вместо непроверенного «production-ready» Compose с Jaeger 1.54/Collector 0.96/Elasticsearch показана топология и условия совместимости. Статически подтверждены два одинаковых host bindings 4317:4317 в старом примере; внутренние listener разных контейнеров не являются этим конфликтом. Описаны Jaeger v2 (источник привязан к **2.22**) и Zipkin exporter с соответствующим API. Согласовано с Q15 B. [Jaeger architecture 2.22](https://www.jaegertracing.io/docs/2.22/architecture/), [APIs](https://www.jaegertracing.io/docs/2.22/architecture/apis/), [Zipkin exporter](https://raw.githubusercontent.com/open-telemetry/opentelemetry-collector-contrib/main/exporter/zipkinexporter/README.md), [Docker port mapping](https://docs.docker.com/engine/network/port-publishing/). Страница 2.23 не прочиталась через web; 2.22 не объявлена latest и не запускалась.

**Q16:** Java Agent 2.x настроен явно как http/protobuf + base endpoint :4318. Signal-specific endpoint отличается полным /v1/traces; порт 4317 сам не включает gRPC. Пример запуска предполагает уже установленный агент, вместо ADD устаревшей версии в Dockerfile. Отключены другие сигналы в этом trace-only примере; sampler 0.1 обозначен политикой, не нормой production. Пространство management.* Boot 3.3 отделено от агента; Observation становится span только с нужной интеграцией. Неполный OrderService заменён компактным компилируемым OrderObservations. Согласовано с Q16 A. [Agent config](https://opentelemetry.io/docs/zero-code/java/agent/configuration/), [OTLP endpoints](https://opentelemetry.io/docs/languages/sdk-configuration/otlp-exporter/), [Boot tracing 3.3](https://docs.spring.io/spring-boot/3.3/reference/actuator/tracing.html).

**Q18:** убраны обещания полной цепочки, точной причины/строки кода и обязательного потока «p99 → причина». Метрики дают масштаб, traces — наблюдаемые операции; гипотезу проверяют несколькими свидетельствами. Один успешный запрос не доказывает восстановление всей нагрузки. Согласовано с Q18 C и границами Q5/Q7/Q14. [OTel traces](https://opentelemetry.io/docs/concepts/signals/traces/).

**Q19:** RED и USE определены как методологии, не готовые функции/гарантия обнаружения причины. У RED запросы одной application-области, знаменатель доли 5xx ограничен наличием трафика, p99 — по включённым совместимым classic buckets. У USE busy/max — занятость, не очередь; обычный major GC — не ресурсная ошибка. Вместо недостоверных PromQL-примеров USE дана таблица смыслов по ресурсам. Согласовано с Q19 B. [RED, Tom Wilkie](https://grafana.com/blog/the-red-method-how-to-instrument-your-services/), [USE, Brendan Gregg](https://www.brendangregg.com/usemethod.html).

**Q20:** registry/serializer отделены от HTTP и scrape; условия Boot ссылаются на Q3/Q10. Нет запрета Protobuf на scrape, форматы согласуются. Сохранён явно синтетический classic text fixture. ServiceMonitor требует Operator/CRD, selectors/namespace, Service и именованный порт; аннотации не означают автоматический scrape. Pushgateway ограничен подходящими service-level batch jobs с управлением жизненным циклом рядов, не универсален для любого cron. Согласовано с Q20 D. [Content negotiation](https://prometheus.io/docs/instrumenting/content_negotiation/), [Operator](https://prometheus-operator.dev/docs/developer/getting-started/), [Pushgateway](https://prometheus.io/docs/practices/pushing/).

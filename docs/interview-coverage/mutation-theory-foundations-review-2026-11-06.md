# Mutation Testing: определения и отличие от покрытия, Q1/Q2

Исправлены только тела теории Q1/Q2. Пролог, остальные 18 тел, все ID/заголовки, метаданные, оглавление и See also сохранены. Production MCQ JSON не менялся. Проверены текущие восемь вариантов и 34 поля пояснений; общей приёмки темы нет.

Q1 теперь определяет чувствительность тестов к выбранным изменениям исследуемого кода. Цикл включает здоровый исходный прогон, настройку области/операторов, отбор подходящих проверок, интерпретацию отдельных статусов и разбор surviving. Убраны требования полного набора тестов для каждого мутанта, «всех возможных мутаций», вывод surviving⇒код не защищён и универсальная формула killed/all. Объяснено различие между упаковкой вариантов и их активацией; пример переключения привязан к проверенной документации Stryker4s.

Q2 сравнивает измеренное исполнение с обнаружением изменения поведения. Вместо неполного Java-фрагмента и неподтверждённого «100% coverage» дана ограниченная таблица: ожидается число 5, изменённый результат — 999, non-null пропускает оба, точное ожидание различает. Boxing `int` в `Integer` описан явно; для nullable-ссылок non-null может быть полезен. Добавлено обнаружение через неожиданное исключение и ограничение гарантии score. Замена на 999 — иллюстрация, а не обещание конкретного оператора PIT.

Ключи D/A фактически защитимы. Ошибочная модель может быть полноценным дистрактором; ложность сама по себе не дефект. C в Q2 даёт законченную ложную причину: coverage якобы уже проверяет правильность результата. Не требуется механически повторять оба термина в каждом варианте. Разную ось Q1 B и спорную полноту Q2 D нельзя закрывать одной грамматической законченностью.

Свежий `gpt-6-luna/medium` сначала прочитал только blind input, выбрал D/A; ответы запечатаны до reveal. Первый B-отчёт **отклонён**: цитаты перепутаны/выдуманы, имена некоторых полей отсутствуют в реальном JSON, причины шаблонные. Его PASS не считается evidence. Последующие два отдельных исправленных прохода проверены на точное совпадение 8 опций и 34 реальных цитат/fieldID и содержат индивидуальные причины. Узкие исправления сохраняют разногласия, замечания и ограничения. Формальная независимая приёмка MCQ владельцем ещё нужна.

Также отозвано ошибочное заявление рецензента, что B в Q2 самый длинный: фактически A=135, B=150, C=143, D=156 символов. A использует противопоставление «а», B — «поскольку», C/D — «поэтому». Оценка сравнительной формы остаётся OPEN; длина сама по себе не даёт FAIL. Исходные отчёты и фактические исправления сохранены отдельно, без перезаписи истории.

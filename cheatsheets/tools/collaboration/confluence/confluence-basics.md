# Confluence: основы

Страницы, пространства, шаблоны и совместное редактирование в Confluence.

## Введение

Confluence — платформа для документации и знаний команды. Страницы, пространства, шаблоны и интеграция с Jira помогают вести требования, архитектуру, ретро и базу знаний в одном месте.

## Пространства и страницы

- **Пространство (Space)** — контейнер для страниц; обычно по команде/проекту/продукту. Права на чтение/редактирование на уровне пространства.
- **Страница** — документ с иерархией (родитель/дочерние). Используют дерево страниц для навигации и структуры.
- **Макеты**: полная ширина, с боковой панелью; выбор при создании или в настройках страницы.


## Редактор и разметка

- Rich-редактор: заголовки, списки, таблицы, вставка кода, макросы.
- Макросы: вставка контента из Jira (список задач, фильтр), диаграммы, календарь, информация о пользователе и др.
- Разметка: поддерживается Markdown и визуальное редактирование; экспорт в PDF/Word при необходимости.


## Шаблоны

Шаблоны задают структуру страницы (например: `Meeting Notes`, `Technical Design`, `Retrospective`, How-to). Использование шаблонов ускоряет создание документов и сохраняет единый формат внутри команды.


## Интеграция с Jira

- Ссылки на задачи Jira в тексте (автоподстановка и отображение статуса).
- Макросы Jira: список задач по JQL, доска, статистика по спринту.
- Связь страницы Confluence с Epic/Story для хранения спецификации и решений рядом с задачей.


## Примеры: структура страницы и ADR

**Типовая структура страницы ретроспективы:** заголовок с датой и спринтом; блок «Что прошло хорошо» (краткие тезисы); «Что улучшить»; «Действия» (с привязкой к задачам Jira по ключам); список участников. Такой формат легко заполнять на ретро и использовать как отчёт.

**ADR (Architecture Decision Record)** — документ с принятым архитектурным решением. Рекомендуемая структура:

1. **Статус** — принято / отложено / устарело.
2. **Контекст** — какая проблема или возможность; ограничения.
3. **Решение** — что выбрали (технология, подход).
4. **Последствия** — плюсы, минусы, риски; что нужно учесть в будущем.
5. **Ссылки** — на обсуждения, Jira Epic/Story, репозитории.

Пример заголовка ADR: «ADR-001: Выбор очереди сообщений (Kafka)». В теле — связный текст по пунктам выше; при необходимости макрос кода для примеров конфигурации. Связь с Jira: в задаче Epic или Story указать ссылку на страницу ADR в Confluence.


## Интеграция с Spring Boot

Confluence REST API позволяет создавать и обновлять страницы, получать контент по ID, искать по CQL. Аутентификация — Basic Auth (email + API Token) или OAuth 2.0. Базовый URL: `https://your-domain.atlassian.net/wiki`.

**Зависимость:** `spring-boot-starter-web` (достаточно для WebClient/RestTemplate).

**Конфигурация (`application.yml`):**

```yaml
confluence:
  base-url: https://your-domain.atlassian.net/wiki
  username: ${CONFLUENCE_USERNAME}
  password: ${CONFLUENCE_API_TOKEN}
```

**Пример сервиса: создание страницы и получение по ID:**

```java
package com.example.confluence.service;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.http.HttpHeaders;
import org.springframework.http.MediaType;
import org.springframework.stereotype.Service;
import org.springframework.web.reactive.function.client.WebClient;

import java.nio.charset.StandardCharsets;
import java.util.Base64;
import java.util.List;
import java.util.Map;

@Service
public class ConfluenceClientService {

    private final WebClient webClient;
    private final String baseUrl;

    public ConfluenceClientService(
            WebClient.Builder builder,
            @Value("${confluence.base-url}") String baseUrl,
            @Value("${confluence.username}") String username,
            @Value("${confluence.password}") String apiToken) {
        this.baseUrl = baseUrl;
        String auth = Base64.getEncoder().encodeToString((username + ":" + apiToken).getBytes(StandardCharsets.UTF_8));
        this.webClient = builder
                .baseUrl(baseUrl)
                .defaultHeader(HttpHeaders.AUTHORIZATION, "Basic " + auth)
                .defaultHeader(HttpHeaders.CONTENT_TYPE, MediaType.APPLICATION_JSON_VALUE)
                .build();
    }

    /**
     * Создание страницы в пространстве. body в формате Confluence Storage (XHTML).
     */
    public Map<String, Object> createPage(String spaceKey, String parentId, String title, String bodyStorage) {
        Map<String, Object> body = Map.of(
                "type", "page",
                "title", title,
                "ancestors", List.of(Map.of("id", parentId)),
                "space", Map.of("key", spaceKey),
                "body", Map.of(
                        "storage", Map.of(
                                "value", bodyStorage,
                                "representation", "storage")));
        return webClient.post()
                .uri("/rest/api/content")
                .bodyValue(body)
                .retrieve()
                .bodyToMono(Map.class)
                .block();
    }

    /**
     * Получить страницу по id.
     */
    public Map<String, Object> getPage(String id) {
        return webClient.get()
                .uri("/rest/api/content/{id}?expand=body.storage,version", id)
                .retrieve()
                .bodyToMono(Map.class)
                .block();
    }
}
```

Формат body в Confluence — Storage (XHTML-подобная разметка). Для простого текста можно обернуть в `<p>...</p>`. API Token создаётся в [Atlassian Account Security API tokens](https://id.atlassian.com/manage-profile/security/api-tokens).


## Кейсы использования с n8n

С **n8n** можно автоматизировать уведомления о новых страницах **Confluence**, создание страниц по шаблону и связку **Jira** **Confluence** **Slack**.

### Кейс 1: Новая страница в Confluence уведомление в Slack

- **Триггер:** Webhook (в Confluence настраивается Incoming Webhook при создании/обновлении страницы — через приложение или Atlassian Automation; webhook вызывает URL n8n).
- **Шаг 2:** отфильтровать по пространству или типу страницы.
- **Шаг 3:** узел Slack — отправить в канал сообщение с названием страницы, автором и ссылкой на страницу.

Итог: команда видит в Slack, когда в Confluence появляется новый документ (например, ADR или ретро).

### Кейс 2: Создание Epic в Jira страница в Confluence по шаблону

- **Триггер:** Jira webhook (событие «Issue created» для типа Epic) или узел Jira по расписанию с фильтром по новым Epic.
- **Шаг 2:** узел Confluence — Create Page: указать пространство, родительскую страницу, заголовок (например, «Epic: {{ $json.fields.summary }}»), тело страницы из шаблона (можно подставить ключ Jira, ссылку на Epic).
- **Шаг 3 (опционально):** обновить задачу Jira — в поле «Confluence page» записать ссылку на созданную страницу (через Jira API в n8n).

Итог: у каждого нового Epic автоматически появляется страница в Confluence для спецификации и решений.

### Кейс 3: Еженедельный дайджест: новые страницы Confluence Slack

- **Триггер:** узел Schedule (раз в неделю).
- **Шаг 2:** узел Confluence — поиск страниц по CQL (например, по дате последнего изменения за неделю в заданном пространстве).
- **Шаг 3:** Code или Set — сформировать текст дайджеста (список страниц с ссылками).
- **Шаг 4:** Slack — отправить в канал `#docs` сообщение с дайджестом.

Итог: команда получает еженедельную сводку по обновлённой документации.

В n8n используются узлы Confluence (учётные данные: URL, email, API Token) и Slack/Jira для связки сценариев.


## Лучшие практики

- Единая структура пространств и именование страниц (дата встреч, префиксы по типу документа).
- Документировать решения (ADR), ретро и онбординг в одном пространстве/разделе.
- Актуальность: указывать дату и владельца; периодически пересматривать устаревшие страницы.
- Ограничение дублирования: ссылки на один источник правды вместо копирования контента.
- Использовать шаблоны для ретро, дизайна и инцидентов для единообразия.
- Поиск и теги для быстрого доступа к нужным страницам.
- Настраивать права по пространствам; не открывать редактирование всему порталу без необходимости.


## Частые вопросы

**Чем пространство (Space) отличается от страницы?**
Пространство — контейнер для страниц (например «Команда X», «Проект Y»). Права задаются на уровне пространства. Страница — документ внутри пространства; страницы образуют иерархию (родитель/дочерние).

**Как создать дочернюю страницу?**
На родительской: «…» Add page (или кнопка Create в боковой панели). При создании выберите родителя. Либо перетащите страницу в дереве.

**Что такое макрос в Confluence?**
Вставка динамического контента: список задач Jira по JQL, таблица, диаграмма, календарь, код. В редакторе: «/» или «+» выбрать макрос.

**Как вставить список задач Jira на страницу?**
В редакторе: «/» Jira. Указать JQL или фильтр; выбрать отображение (таблица, список).

**Как связать страницу Confluence с задачей Jira?**
В задаче Jira: поле «Confluence page» или ссылка в описании. В Confluence: ввести ключ `PROJ-123` — подставится ссылка. Макрос «Jira Issues» показывает связанные задачи.

**Как экспортировать страницу в PDF?**
«…» Export to PDF. Для пространства целиком — Space settings Export.

**Как настроить права на пространство?**
Space settings Permissions. View, Edit, Admin по группам/пользователям.

**Что такое лейбл (label)?**
Метка на странице для категоризации и поиска. По лейблам удобно фильтровать.

**Как откатить страницу к предыдущей версии?**
«…» Page history выбрать версию Restore.

**Что такое ADR (Architecture Decision Record)?**
Документ с архитектурным решением: контекст, решение, последствия. Часто в Confluence по шаблону; связь с Jira Epic/Story.

## Чек-листы

### Создание страницы

- [ ] Выбрать пространство и родительскую страницу (если нужна иерархия).
- [ ] Выбрать шаблон (Meeting Notes, Technical Design и т.д.).
- [ ] Заполнить заголовок и контент; при необходимости добавить макросы (Jira, код, таблицы).
- [ ] Добавить лейблы для поиска.

### Поддержание актуальности

- [ ] Периодически пересматривать страницы; помечать устаревшие или архивировать.
- [ ] Ссылаться на одну страницу (источник правды) вместо копирования.
- [ ] Обновлять ссылки на задачи Jira при изменении ключей или статусов.

### Ретроспектива (шаблон в Confluence)

- [ ] Что прошло хорошо.
- [ ] Что улучшить.
- [ ] Действия (с привязкой к задачам Jira при необходимости).
- [ ] Дата и участники.


## Макросы Confluence (краткий список)

| Макрос | Назначение |
|--------|------------|
| **Jira** | Список задач по JQL или фильтру; таблица/список. |
| **Expand** | Сворачиваемый блок контента. |
| **Code** | Блок кода с подсветкой языка. |
| **Table** | Таблица. |
| **Info / Warning / Note** | Цветные блоки для подсказок и предупреждений. |
| **Children** | Список дочерних страниц. |
| **Page Tree** | Дерево страниц для навигации. |
| **User** | Информация о пользователе. |
| **Calendar** | Календарь. |
| **Diagram** | Диаграммы (например draw.io). |

Ввод «/» в редакторе открывает список макросов.


## Решение проблем

| Симптом | Возможная причина | Действие |
|--------|-------------------|----------|
| Не вижу пространство/страницу | Нет прав | Проверить Space settings Permissions; запросить доступ у владельца. |
| Макрос Jira не показывает задачи | Неверный JQL или нет прав на задачи | Проверить JQL в отдельном фильтре в Jira; проверить права на проект. |
| Не сохраняется страница | Конфликт версий или сеть | Обновить страницу и повторить; проверить подключение. |

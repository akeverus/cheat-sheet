# Безопасность данных (Data Security)

Шифрование, хеширование, защита данных в покое и при передаче.

**Дата последнего обновления:** 2026-02-11

## Полезные ссылки

[OWASP](https://owasp.org/)
[CWE](https://cwe.mitre.org/)

## Обзор

Документ в разработке. Основные темы: шифрование данных (AES, TLS), хеширование паролей (bcrypt, Argon2), защита персональных данных (PII), маскирование данных.

См. также: [Security Practices](../security-practices.md) — общие практики и процессы безопасности.

## Введение в **Insomnia**

**Insomnia** — **REST** клиент для тестирования и разработки **API**.

### Основные возможности

- Создание **HTTP** запросов
- Управление окружениями
- Плагины и расширения
- **GraphQL** поддержка

## Создание запросов

**Insomnia** предоставляет интуитивный интерфейс для создания **HTTP** запросов: выбор метода (**GET**, **POST**, **PUT**, **DELETE** и др.), ввод **URL**, заголовков и тела (**JSON**, **form-data**, **raw**). Поддерживаются переменные окружения в виде `{{ variable }}` в **URL** и теле запроса.

Пример **GET** с базовым **URL** из окружения: `{{ base_url }}/api/users`.

## Окружения

Окружения (**Environments**) позволяют переключать конфигурации (например, `base_url`, `token`) для **dev**, **staging**, **production**. Переменные задаются в разделе **Manage Environments** и подставляются в запросы при выборе активного окружения.

## Лучшие практики

1. Организация запросов по папкам по доменам или сценариям.
2. Использование переменных для **URL**, токенов и общих заголовков.
3. Автоматизация повторяемых проверок через встроенные тесты и экспорт коллекций.

## Введение в Postman

**Postman** — инструмент для разработки, тестирования и документирования **API**.

### Основные возможности

- Создание **HTTP** запросов
- Управление коллекциями
- Автоматизация тестов
- Генерация документации

## Создание запросов

Пример **HTTP**-запроса в **Postman** (GET с заголовками).

```http
# GET-запрос с заголовками авторизации и типа содержимого
GET https://api.example.com/users
Authorization: Bearer token
Content-Type: application/json
```

## Коллекции

Коллекции позволяют организовывать запросы по проектам и командам.

## Переменные и окружения

В **Environments** задаются переменные (например, `base_url`, `token`), подставляемые в **URL** и тело запроса как `{{ variable }}`. Переключение окружения (**dev**, **staging**, **prod**) меняет значения без правки запросов. В коллекциях можно задавать переменные на уровне коллекции.

## Автоматизация

**Postman** поддерживает скрипты в разделах **Pre-request Script** и **Tests** (JavaScript). Для **CI/CD** используется **Newman** — **CLI** для запуска коллекций: `newman run collection.json --environment env.json`. Позволяет проверять коды ответов, тело и время ответа в пайплайне.

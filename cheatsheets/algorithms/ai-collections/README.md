# AI Collections

Раздел задуман как хаб для AI-сгенерированных коллекций алгоритмических задач и решений: тематические подборки (DP, графы, строки), маршруты подготовки к интервью, подборки по источникам (LeetCode top-100, NeetCode-150, Grokking patterns). Сейчас каталог пуст — это точка старта, а не готовый набор материалов.

Использовать раздел стоит, когда нужна кураторская подборка задач под конкретную цель (например, «30 задач на DP за 2 недели»), а не справочник по алгоритмам. Для базовых материалов по алгоритмам — соседние разделы `algorithms/algorithmic-paradigms/`, `algorithms/data-structures/`, `algorithms/problems/`.

## Когда брать этот раздел

- Нужна **готовая траектория** прохождения 50-150 задач (а не справочник алгоритмов).
- Готовитесь к конкретному формату интервью (LeetCode-style, FAANG, системный раунд).
- Хотите собрать свою коллекцию задач по паттернам через AI-инструменты.

**Когда не брать:** изучение алгоритмов с нуля — начать с `algorithms/algorithmic-paradigms/` и `algorithms/data-structures/`; подготовка к теоретическому устному собеседованию — `interview/algorithms/`.

## Что стоит покрыть

Раздел пуст. При наполнении разумно добавить:

- Подборки по паттернам: sliding window, two pointers, binary search, backtracking, DP, BFS/DFS.
- Тематические пачки: массивы, строки, деревья, графы, heap/priority queue.
- Шаблоны промптов для генерации задач и валидации решений через AI.
- Маршруты подготовки: 2 недели / 1 месяц / 3 месяца.
- Разбор ошибок типовых решений: тайм-аут, переполнение, edge cases.

## Маршруты чтения

- **Самоподготовка к интервью (план на 4 недели):** 5 задач/день по паттерну дня из `algorithmic-paradigms/` + `problems/`.
- **Быстрый повтор за 3 дня:** топ-20 задач по структурам данных из `data-structures/`.
- **Глубокая проработка одной темы:** пара `паттерн 10-15 задач` из `algorithmic-paradigms/`.

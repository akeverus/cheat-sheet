## Описание алгоритма

Треугольник Паскаля представляет собой расположение биномиальных коэффициентов в треугольной форме. Числа в треугольнике Паскаля расположены так, что каждое из них представляет собой сумму двух чисел непосредственно над ним.

Ниже — генерация и печать треугольника в `Java`.

### Структура треугольника

Первые строки треугольника:

```text
        1
       1 1
      1 2 1
     1 3 3 1
    1 4 6 4 1
   1 5 10 10 5 1
```

Каждое число в треугольнике является суммой двух чисел непосредственно над ним.

### Биномиальные коэффициенты

Элемент (n, k) равен C(n,k) = n! / ((n−k)! k!). Для печати треугольника эффективнее рекуррентное правило: значение = сумма двух выше.

## Реализация на Java

### Подход 1: Рекурсия с факториалом

C(n,k) через факториалы. Неэффективно: одни и те же факториалы считаются многократно.

```java
// Факториал для C(n,k) = n!/((n-k)! k!)
public int factorial(int i) {
    if (i == 0) {
        return 1;
    }
    return i * factorial(i - 1);
}
```

Печать треугольника через factorial(i)/(factorial(i-k)*factorial(k)).

```java
private void printUseRecursion(int n) {
    for (int i = 0; i <= n; i++) {
        for (int j = 0; j <= n - i; j++) {
            System.out.print(" ");
        }
        for (int k = 0; k <= i; k++) {
            System.out.print(" " + factorial(i) / (factorial(i - k) * factorial(k)));
        }
        System.out.println();
    }
}
```

## Подход 2: Биномиальное разложение

В начале строки 1; следующий элемент: k = k * (line — i) / i. Один проход, O(n²) по времени, O(1) по памяти.

```java
// Каждый элемент строки из предыдущего: k = k*(line-i)/i
public void printUseBinomialExpansion(int n) {
    for (int line = 1; line <= n; line++) {
        for (int j = 0; j <= n - line; j++) {
            System.out.print(" ");
        }

        int k = 1;
        for (int i = 1; i <= line; i++) {
            System.out.print(k + " ");
            k = k * (line - i) / i;
        }
        System.out.println();
    }
}
```

## Подход 3: Динамическое программирование

Заполняем матрицу: первый и последний элемент строки — 1; остальные triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]. Удобно, если нужен доступ к любому элементу.

```java
// triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]
public int[][] generatePascalTriangle(int n) {
    int[][] triangle = new int[n][];

    for (int i = 0; i < n; i++) {
        triangle[i] = new int[i + 1];
        triangle[i][0] = 1;
        triangle[i][i] = 1;

        for (int j = 1; j < i; j++) {
            triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j];
        }
    }

    return triangle;
}

public void printPascalTriangle(int n) {
    int[][] triangle = generatePascalTriangle(n);

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n - i; j++) {
            System.out.print(" ");
        }
        for (int j = 0; j <= i; j++) {
            System.out.print(triangle[i][j] + " ");
        }
        System.out.println();
    }
}
```

### Получение конкретного элемента

Рекурсия: C(row,col) = C(row-1,col-1) + C(row-1,col); база — col==0 или col==row 1.

```java
public int getPascalValue(int row, int col) {
    if (col == 0 || col == row) {
        return 1;
    }
    return getPascalValue(row - 1, col - 1) + getPascalValue(row - 1, col);
}
```

### Оптимизированная версия с мемоизацией

Кэш по ключу "row,col" избегает повторных вычислений.

```java
private Map<String, Integer> memo = new HashMap<>();

public int getPascalValueMemoized(int row, int col) {
    if (col == 0 || col == row) {
        return 1;
    }

    String key = row + "," + col;
    if (memo.containsKey(key)) {
        return memo.get(key);
    }

    int value = getPascalValueMemoized(row - 1, col - 1) +
                getPascalValueMemoized(row - 1, col);
    memo.put(key, value);
    return value;
}
```

## Сравнение подходов

| Подход | Временная сложность | Пространственная сложность | Когда использовать |
|--------|---------------------|----------------------------|-------------------|
| Рекурсия с факториалом | O(n³) | O(n) | Не рекомендуется |
| Биномиальное разложение | O(n²) | O(1) | Для печати |
| Динамическое программирование | O(n²) | O(n²) | Для хранения |

## Сложность

Рекурсия с факториалом — O(n³) по времени из-за повторных вычислений. Биномиальное разложение — O(n²) по времени, O(1) по памяти. ДП — O(n²) по времени и памяти.

## Особенности

Для одной печати лучше биномиальное разложение. Если нужен доступ к элементам — ДП. Рекурсия с факториалом наглядная, но медленная.

## Применение

Треугольник Паскаля используется в комбинаторике, теории вероятностей, биномиальных разложениях и алгоритмах.

## Варианты задачи

### Вариант 1: Получение n-й строки

n-я строка без полной матрицы: следующий элемент из предыдущего по формуле коэффициента.

```java
public List<Integer> getRow(int rowIndex) {
    List<Integer> row = new ArrayList<>();
    row.add(1);

    for (int i = 1; i <= rowIndex; i++) {
        row.add((int)((long)row.get(i-1) * (rowIndex - i + 1) / i));
    }

    return row;
}
```

### Вариант 2: Сумма элементов в строке

Сумма строки n равна 2^n.

```java
public int sumOfRow(int rowIndex) {
    return (int) Math.pow(2, rowIndex);
}
```

### Вариант 3: Проверка, является ли число числом Паскаля

```java
public boolean isPascalNumber(int num) {
    for (int n = 0; n <= num; n++) {
        for (int k = 0; k <= n; k++) {
            if (binomialCoefficient(n, k) == num) {
                return true;
            }
        }
    }
    return false;
}

private int binomialCoefficient(int n, int k) {
    if (k == 0 || k == n) {
        return 1;
    }
    return binomialCoefficient(n-1, k-1) + binomialCoefficient(n-1, k);
}
```

```kotlin
fun generatePascalTriangleK(n: Int): Array<IntArray> {
    val triangle = Array(n) { IntArray(it + 1) }

    for (i in 0 until n) {
        triangle[i][0] = 1
        triangle[i][i] = 1

        for (j in 1 until i) {
            triangle[i][j] = triangle[i - 1][j - 1] + triangle[i - 1][j]
        }
    }

    return triangle
}

fun getRowK(rowIndex: Int): List<Int> {
    val row = mutableListOf(1)
    for (i in 1..rowIndex) {
        row.add((row[i - 1].toLong() * (rowIndex - i + 1) / i).toInt())
    }
    return row
}
```

## Когда использовать

Биномиальное разложение — когда нужна только печать и важна экономия памяти. Динамическое программирование — когда нужен доступ к элементам или многократное использование. Рекурсию с факториалом лучше не использовать в продакшене.

## Лучшие практики

Не считайте C(n,k) через факториалы для каждой ячейки — используйте рекуррентное правило или один проход. При больших n коэффициенты быстро растут: используйте `long` или `BigInteger`, либо вычисления по модулю. Для печати достаточно одной-двух строк. Явно зафиксируйте нумерацию строк (0 или 1). В тестах проверяйте n=0, n=1 и известные строки (n=5, 10).

## Решение проблем

| Симптом | Возможная причина | Решение |
|---------|-------------------|---------|
| Переполнение int при больших n | Биномиальные коэффициенты растут быстро | Использовать long или BigInteger; либо считать по модулю |
| Медленная работа рекурсии | Многократный пересчёт одних и тех же C(n,k) | Мемоизация или построение матрицы ДП вместо рекурсии по факториалу |
| Неверная строка при getRow | Путаница индекса (0-based vs 1-based) | Документировать и единообразно использовать выбранную индексацию |

## Частые вопросы

**Почему биномиальное разложение быстрее рекурсии с факториалом?** Рекурсия считает факториал для каждой ячейки заново и даёт O(n³). Разложение вычисляет следующее значение из предыдущего за O(1) на элемент.

**Как получить только k-й элемент n-й строки без всей строки?** Можно итеративно считать один коэффициент по формуле C(n,k) = C(n,k-1)*(n-k+1)/k, начиная с 1.

**Когда использовать BigInteger?** При n порядка сотен и больше коэффициенты в середине строки могут не помещаться в long; для точных значений нужен BigInteger или работа по модулю.

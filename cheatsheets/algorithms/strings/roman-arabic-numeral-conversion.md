## Описание алгоритма

Древние римляне разработали собственную систему счисления, называемую римскими цифрами. Система использует буквы с разными значениями для представления чисел. Римские цифры до сих пор используются в некоторых второстепенных приложениях.

В этом уроке мы реализуем простые преобразователи, которые будут преобразовывать числа из одной системы в другую.

## Римские цифры

В римской системе у нас есть 7 символов, которые представляют числа. `I` представляет 1, `V` представляет 5, `X` представляет 10, `L` представляет 50, `C` представляет 100, `D` представляет 500, `M` представляет 1000. Эти символы используются в различных комбинациях для представления чисел от 1 до 3999.

### Вычитающая запись

Первоначально люди представляли 4 с `IIII` или 40 с `XXXX`. Это может быть довольно неудобно читать. Также легко принять четыре символа рядом друг с другом за три символа. Римские цифры используют вычитающую запись, чтобы избежать таких ошибок. Вместо того, чтобы говорить «четыре раза один» (`IIII`), можно сказать, что на один меньше пяти (`IV`).

Насколько это важно с нашей точки зрения? Это важно, потому что вместо простого сложения чисел символ за символом нам может потребоваться проверить следующий символ, чтобы определить, нужно ли прибавлять или вычитать число. Это усложняет алгоритм преобразования, но делает запись более компактной и читаемой.

### Enum для римских цифр

Давайте определим перечисление для представления римских цифр. Это позволит нам структурированно работать с римскими цифрами и их значениями.

```java
// Перечисление римских цифр с базовыми и вычитающими парами (IV, IX, XL и т.д.)
enum RomanNumeral {
    I(1), IV(4), V(5), IX(9), X(10),
    XL(40), L(50), XC(90), C(100),
    CD(400), D(500), CM(900), M(1000);

    private int value;

    RomanNumeral(int value) {
        this.value = value;
    }

    public int getValue() {
        return value;
    }

    public static List<RomanNumeral> getReverseSortedValues() {
        return Arrays.stream(values())
            .sorted(Comparator.comparing((RomanNumeral e) -> e.value).reversed())
            .collect(Collectors.toList());
    }
}
```

Обратите внимание, что мы определили дополнительные символы, чтобы помочь с вычитающей записью. Мы также определили дополнительный метод с именем `getReverseSortedValues()`.

Этот метод позволит нам явно получить определенные римские цифры в порядке убывания значения.

## Реализация на Java

### Преобразование римских в арабские (Java)

**Римские цифры могут представлять только целые числа от 1 до `4000`. Мы можем использовать следующий алгоритм для преобразования римской цифры в арабскую (перебор символов в обратном порядке от M до I):**

```text
LET numeral be the input String representing an Roman Numeral
LET symbol be initially set to RomanNumeral.values()[0]
WHILE numeral.length > 0:
    IF numeral starts with symbol's name:
        add symbol's value to the result
        remove the symbol's name from the numeral's beginning
    ELSE:
        set symbol to the next symbol
```

Далее мы можем реализовать алгоритм на `Java`. Алгоритм работает путём последовательного поиска наибольших возможных римских символов в строке и добавления их значений к результату. Наконец, мы можем протестировать реализацию, чтобы убедиться в её корректности.

```java
@Test
void given2018Roman_WhenConvertingToArabic_ThenReturn2018() {
    String roman2018 = "MMXVIII";
    int result = RomanArabicConverter.romanToArabic(roman2018);
    assertThat(result).isEqualTo(2018);
}
```

### Альтернативная реализация

```java
public static int romanToArabicAlternative(String s) {
    Map<Character, Integer> map = new HashMap<>();
    map.put('I', 1);
    map.put('V', 5);
    map.put('X', 10);
    map.put('L', 50);
    map.put('C', 100);
    map.put('D', 500);
    map.put('M', 1000);

    int result = 0;
    int prevValue = 0;

    for (int i = s.length() - 1; i >= 0; i--) {
        int currentValue = map.get(s.charAt(i));
        if (currentValue < prevValue) {
            result -= currentValue;
        } else {
            result += currentValue;
        }
        prevValue = currentValue;
    }

    return result;
}
```

## Преобразование арабских в римские

Мы можем использовать следующий алгоритм для преобразования арабских цифр в римские (перебирая символы в обратном порядке от `M` до `I`). Алгоритм работает путём последовательного вычитания наибольших возможных значений римских символов из числа и добавления соответствующих символов к результату. Теперь мы можем реализовать алгоритм.

```java
public static String arabicToRoman(int number) {
    if ((number <= 0) || (number > 4000)) {
        throw new IllegalArgumentException(number + " is not in range (0,4000]");
    }

    List<RomanNumeral> romanNumerals = RomanNumeral.getReverseSortedValues();
    int i = 0;
    StringBuilder sb = new StringBuilder();

    while ((number > 0) && (i < romanNumerals.size())) {
        RomanNumeral currentSymbol = romanNumerals.get(i);

        if (currentSymbol.getValue() <= number) {
            sb.append(currentSymbol.name());
            number -= currentSymbol.getValue();
        } else {
            i++;
        }
    }

    return sb.toString();
}
```

Наконец, мы можем протестировать реализацию, чтобы убедиться в её корректности. Тестирование должно покрывать граничные случаи, такие как минимальные и максимальные значения, а также различные комбинации вычитающей записи.

### Альтернативная реализация

```java
public static String arabicToRomanAlternative(int num) {
    String[] thousands = {"", "M", "MM", "MMM"};
    String[] hundreds = {"", "C", "CC", "CCC", "CD", "D", "DC", "DCC", "DCCC", "CM"};
    String[] tens = {"", "X", "XX", "XXX", "XL", "L", "LX", "LXX", "LXXX", "XC"};
    String[] ones = {"", "I", "II", "III", "IV", "V", "VI", "VII", "VIII", "IX"};

    return thousands[num / 1000] +
           hundreds[(num % 1000) / 100] +
           tens[(num % 100) / 10] +
           ones[num % 10];
}
```

## Сложность

### Временная сложность

Временная сложность преобразования римских цифр в арабские составляет `O(n)`, где `n` — длина римской строки. Это связано с тем, что алгоритм проходит по строке один раз, проверяя каждый символ. Преобразование арабских цифр в римские имеет временную сложность `O(1)` — константное время, так как максимальное число ограничено значением 4000, и алгоритм всегда выполняет фиксированное количество операций.

### Пространственная сложность

Пространственная сложность обоих преобразований составляет `O(1)` — только константная память. Это связано с тем, что алгоритмы не требуют дополнительных структур данных, размер которых зависит от входных данных, и используют только фиксированное количество переменных для хранения промежуточных результатов.

## Особенности

Алгоритмы просты для понимания, что делает их подходящими для образовательных целей и изучения основ работы с римскими цифрами. Оба преобразования эффективны и работают за линейное или константное время, что делает их пригодными для практического использования. Однако алгоритмы имеют ограничения — они работают только с числами от 1 до 4000, что соответствует классическому диапазону римских цифр.

## Применение

Преобразование римских цифр используется в различных областях. В обработке исторических документов преобразование римских цифр необходимо для корректной интерпретации дат и чисел в старых документах. В образовательных приложениях преобразование римских цифр используется для обучения студентов работе с различными системами счисления. В играх и головоломках римские цифры используются для создания разнообразного контента и заданий. В валидации данных преобразование римских цифр используется для проверки корректности входных данных. В форматировании дат римские цифры используются для представления годов и других временных меток в более читаемом формате.

public static boolean isValidRoman(String s) {

## Реализация на Kotlin

### Enum для римских цифр

```kotlin
enum class RomanNumeralK(val value: Int) {
    I(1), IV(4), V(5), IX(9), X(10),
    XL(40), L(50), XC(90), C(100),
    CD(400), D(500), CM(900), M(1000);

    companion object {
        fun getReverseSortedValues(): List<RomanNumeralK> {
            return values().sortedByDescending { it.value }
        }
    }
}
```

### Преобразование римских в арабские (Kotlin)

```kotlin
fun romanToArabicK(input: String): Int {
    var romanNumeral = input.uppercase()
    var result = 0
    val romanNumerals = RomanNumeralK.getReverseSortedValues()
    var i = 0

    while (romanNumeral.isNotEmpty() && i < romanNumerals.size) {
        val symbol = romanNumerals[i]

        if (romanNumeral.startsWith(symbol.name)) {
            result += symbol.value
            romanNumeral = romanNumeral.substring(symbol.name.length)
        } else {
            i++
        }
    }

    if (romanNumeral.isNotEmpty()) {
        throw IllegalArgumentException("$input cannot be converted to a Roman Numeral")
    }

    return result
}
```

## Когда использовать

Используйте `enum` подход, когда нужна читаемость и структурированность кода. Этот подход особенно полезен, когда работаете с ограниченным набором значений, что позволяет явно определить все возможные варианты римских цифр и их значения. `Enum` подход также обеспечивает типобезопасность и предотвращает ошибки при работе с римскими цифрами.

Используйте `Map` подход, когда нужна гибкость и простота реализации. Этот подход особенно полезен, когда работаете с небольшими числами и не требуется сложная структура данных. `Map` подход также позволяет легко изменять значения римских цифр без изменения структуры кода.

## Лучшие практики

Диапазон классических римских цифр ограничен 1–3999 (`MMMCMXCIX`). Для нуля или отрицательных чисел явно оговорите контракт (исключение, `null`, пустая строка). Это гарантирует корректное поведение алгоритма во всех возможных случаях и предотвращает ошибки при работе с недопустимыми значениями.

Валидация критически важна при разборе римской строки. Проверяйте допустимые символы (`I`, `V`, `X`, `L`, `C`, `D`, `M`) и порядок (не более трёх подряд одинаковых, вычитающие пары только в допустимых комбинациях: `IV`, `IX`, `XL`, `XC`, `CD`, `CM`). Это гарантирует корректность входных данных и предотвращает ошибки при преобразовании.

Римские арабские преобразование требует правильного обхода строки. Обходите строку слева направо; если текущее значение меньше следующего — вычитайте (вычитающая запись), иначе прибавляйте. Это гарантирует корректную обработку вычитающей записи и правильное преобразование римских цифр в арабские числа.

Арабские римские преобразование требует использования отсортированного по убыванию списка значений (`M`, `CM`, `D`, `CD`, `C`, `XC`, …) и последовательного вычитания из числа максимально возможного значения, дописывая соответствующий символ. Это гарантирует создание корректной римской записи числа.

Тестирование должно покрывать все граничные случаи. Проверьте граничные значения (1, 4, 9, 40, 90, 400, 900, 3999), невалидные строки (`IIII`, `VV`, пустая строка), регистр символов при разборе. Это гарантирует корректную работу алгоритма во всех возможных ситуациях.

## Решение проблем

При работе с преобразованием римских и арабских чисел могут возникать различные проблемы. Если преобразование даёт неверные результаты, убедитесь, что входные данные корректны и соответствуют правилам римских цифр. Если возникают проблемы с вычитающей записью, проверьте правильность обработки пар символов, таких как `IV`, `IX`, `XL`, `XC`, `CD`, `CM`.

Проблемы с валидацией часто связаны с неправильной проверкой входных данных. Убедитесь, что вы проверяете все допустимые символы и правильность их расположения. Также проверьте обработку граничных случаев, таких как пустые строки или числа вне допустимого диапазона.

Проблемы с производительностью редко возникают при работе с римскими цифрами, так как алгоритмы имеют линейную или константную сложность. Однако при работе с большим количеством преобразований рассмотрите возможность кэширования результатов или использования более эффективных структур данных.

## Частые вопросы

**Как обрабатывать числа больше 3999?** Классические римские цифры ограничены диапазоном 1–3999. Для больших чисел можно использовать расширенную систему с надстрочными символами или просто вернуть ошибку, в зависимости от требований приложения.

**Как обрабатывать регистр символов?** Римские цифры обычно записываются заглавными буквами, но алгоритмы должны быть нечувствительны к регистру. Используйте `toUpperCase()` или `uppercase()` для нормализации входных данных перед обработкой.

**Как валидировать римские цифры?** Используйте регулярные выражения для проверки корректности римских цифр. Проверьте допустимые символы, правильность вычитающей записи и отсутствие недопустимых комбинаций, таких как `IIII` или `VV`.

**Как обрабатывать нуль и отрицательные числа?** Классические римские цифры не поддерживают нуль и отрицательные числа. Определите контракт для вашего приложения: выбрасывать исключение, возвращать `null` или использовать специальное представление.

## Глоссарий терминов

**Римские цифры** — система счисления, использующая буквы латинского алфавита для представления чисел. Римские цифры используются в различных областях, включая исторические документы, образование и игры.

**Вычитающая запись** — способ записи римских цифр, при котором меньшее значение вычитается из большего для создания более компактной записи. Например, `IV` вместо `IIII` для числа 4.

**Арабские цифры** — система счисления, использующая десять символов (0–9) для представления чисел. Арабские цифры являются стандартной системой счисления в большинстве современных приложений.

**Enum** — перечисление, тип данных в программировании, который определяет набор именованных констант. В контексте римских цифр `enum` используется для представления символов и их значений.

**Валидация** — процесс проверки корректности входных данных. В контексте римских цифр валидация включает проверку допустимых символов, правильности вычитающей записи и соответствия правилам римских цифр.

## Дополнительные примеры использования

Преобразование римских и арабских чисел используется в различных областях. В системах обработки документов преобразование римских цифр необходимо для корректной интерпретации дат и чисел в исторических документах. В образовательных системах преобразование римских цифр используется для обучения студентов работе с различными системами счисления и понимания исторических методов записи чисел.

В игровых системах римские цифры используются для создания разнообразного контента и заданий, что делает игры более интересными и образовательными. В системах форматирования данных римские цифры используются для представления чисел в более читаемом формате, особенно при работе с датами и временными метками.

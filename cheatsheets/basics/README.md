# Основы

Раздел посвящён базовым концепциям: компьютерные науки, программирование, сети, операционные системы, Git, чистый код.

## Принципы оформления

Текст во всех документах папки **basics** должен быть **максимально человекочитаемым, легко запоминаемым и хорошо визуально восприниматься**. Роль папки — **фундаментальные основы**, не дублирующие специализированные разделы (algorithms, frameworks, testing, security).

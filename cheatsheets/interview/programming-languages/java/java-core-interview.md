## Q1. (!) Что такое ключевое слово final?

Ключевое слово final в `Java` может быть применено к классу, методу, полю или локальной переменной.

1. Класс: класс с final не может быть наследован.
2. Метод: метод с final не может быть переопределен в подклассах.
3. Поле: значение нельзя изменить после присваивания; должно быть инициализировано при объявлении или в конструкторе.
4. Локальная переменная: значение не может быть изменено после присваивания в пределах блока.

```java
public final class UtilityClass {
    private final String name = "MyApp";

    public final void process() { }

    public void demo() {
        final int max = 3;
        // max = 5; // Ошибка компиляции
    }
}
```

Использование final помогает создавать иммутабельные объекты и предотвращать изменение или наследование элементов класса.

## Q2. Что такое метод по умолчанию?

Метод по умолчанию (default method) в `Java` 8 — метод с реализацией внутри интерфейса. Классы, реализующие интерфейс, могут использовать эту реализацию или переопределить метод. Помечается ключевым словом default.

```java
interface MyInterface {
    void method1();

    default void method2() {
        System.out.println("Метод по умолчанию");
    }
}

class MyClass implements MyInterface {
    public void method1() {
        System.out.println("Реализация метода1");
    }
}
// myObj.method2() использует реализацию по умолчанию
```

Методы по умолчанию позволяют добавлять новые методы в интерфейсы без нарушения существующих реализаций.

## Q3. Что такое статические члены класса?

Статические члены класса принадлежат самому классу, а не экземпляру. Объявляются с static.

Статические переменные: общие для всех экземпляров класса, инициализируются один раз при загрузке класса, доступны через имя класса или из любого экземпляра.

Статические методы: вызываются без создания экземпляра, обрабатывают только статические данные, не имеют доступа к нестатическим полям и методам.

Преимущества: удобный доступ к общим данным, экономия памяти. Осторожность: глобальная видимость может вызывать проблемы с многопоточностью и усложнять тестирование.

## Q4. Можно ли объявить класс `abstract`, если в нём нет `abstract` членов? Какова может быть цель такого класса?

Да. Такой класс называют «частично абстрактным».

Цели: (1) Запрет на создание экземпляров — абстрактный класс нельзя инстанциировать напрямую, только через подклассы. (2) Группировка функциональности — общая реализация и неабстрактные методы для подклассов, организация иерархии классов. Объявление класса абстрактным без абстрактных методов имеет смысл, когда нужно запретить создание объектов этого класса или задать базовую структуру для наследников.

## Q5. Что такое `Constructor Chaining`?

Цепочка конструкторов — вызов одного конструктора из другого в том же классе (this) или в родительском (super). Вызов должен быть первой строкой в конструкторе.

```java
public class MyClass {
    private int x, y;

    public MyClass() {
        this(0);
    }

    public MyClass(int x) {
        this(x, 0);
    }

    public MyClass(int x, int y) {
        this.x = x;
        this.y = y;
    }
}

public class SubClass extends SuperClass {
    public SubClass(int x, int y, int z) {
        super(x, y);
        this.z = z;
    }
}
```

this(...) — вызов другого конструктора того же класса. super(...) — вызов конструктора родительского класса. Упрощает инициализацию и переиспользование кода.

## Q6. (!) Что такое `Overriding` и `Overloading` методов?

Переопределение (overriding) — метод с тем же именем и сигнатурой в подклассе заменяет реализацию из родителя. При вызове на объекте подкласса выполняется переопределённый метод.

```java
class Animal {
    public void sound() { System.out.println("Animal"); }
}
class Cat extends Animal {
    @Override
    public void sound() { System.out.println("Meow"); }
}
```

Перегрузка (overloading) — методы с одним именем, но разной сигнатурой (типы/количество аргументов) в одном классе. Компилятор выбирает метод по аргументам вызова.

```java
class Calculator {
    public int add(int a, int b) { return a + b; }
    public double add(double a, double b) { return a + b; }
}
```

Различие: overriding меняет поведение в наследнике; overloading — несколько вариантов метода с разной сигнатурой в одном классе.

## Q7. Можно ли переопределить static метод?

Нет. Статический метод принадлежит классу, а не экземпляру. В подклассе метод с тем же именем и сигнатурой не переопределяет, а скрывает (hiding) метод родителя. Какой метод вызывается, определяется по типу ссылки (классу), а не по типу объекта.

```java
class Parent {
    public static void staticMethod() { System.out.println("Parent"); }
}
class Child extends Parent {
    public static void staticMethod() { System.out.println("Child"); }
}

Parent.staticMethod();       // Parent
Child.staticMethod();        // Child
Parent p = new Child();
p.staticMethod();            // Parent (по типу ссылки)
```

## Q8. (!) Что такое `Immutable` класс и как его создать?

Неизменяемый класс — объекты нельзя изменить после создания. Поля приватные, доступ только через геттеры. Обеспечивает потокобезопасность и предсказуемость данных.

Шаги создания: (1) все поля private final, инициализация в конструкторе; (2) только геттеры, без сеттеров; (3) класс final; (4) если есть ссылки на объекты — использовать неизменяемые или защищённые копии.

```java
public final class Person {
    private final String name;
    private final int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public int getAge() { return age; }
}
```

## Q9. Как сравнить два значения `Enum`: с помощью equals() или с помощью ==?

Рекомендуется использовать `==`. Значения `Enum` — синглтоны в рамках типа, поэтому `==` проверяет совпадение одной и той же константы. `equals()` для `Enum` по умолчанию ведёт себя так же, но `==` быстрее и явнее.

```java
enum Color { RED, BLUE, GREEN }

Color c1 = Color.RED;
Color c2 = Color.RED;
System.out.println(c1 == c2); // true
```

Если `Enum` переопределяет equals(), поведение может отличаться — тогда ориентироваться на контракт переопределения.

## Q10. Что такое блок инициализатора? Что такое статический блок инициализатора?

Блок инициализатора — блок кода в теле класса без модификатора; выполняется при создании каждого экземпляра перед конструктором.

Статический блок инициализатора — static { ... }; выполняется один раз при загрузке класса. Порядок при создании объекта: статические блоки и поля → блоки и поля экземпляра → конструктор.

```java
public class MyClass {
    private int counter;
    private static String message;

    { counter = 0; }           // при каждом new MyClass()
    static { message = "Hi"; } // один раз при загрузке класса

    public MyClass() { }
}
```

## Q11. (!) Что такое `Marker Interface`?

Маркерный интерфейс — интерфейс без методов, используется только для пометки типа (метаданные на уровне типа).

Примеры в `Java`: `Serializable` (сериализация), `Cloneable` (клонирование), `RandomAccess` (эффективный доступ по индексу в коллекциях).

Пометка класса маркерным интерфейсом позволяет системе или фреймворку обрабатывать такие классы особым образом (например, сериализация, клонирование) без добавления методов. В современных версиях `Java` часто заменяются аннотациями, но маркеры по-прежнему используются (`Serializable`, `Cloneable`).

## Q12. Что такое `Var-args`? Каковы ограничения для `Var-args`? Как вы можете использовать его внутри тела метода?

`Var-args` — произвольное количество аргументов одного типа в методе. Объявление: тип и троеточие, например int... numbers. Внутри метода параметр воспринимается как массив (int[]).

Ограничения: (1) параметр `var-args` должен быть последним в списке аргументов; (2) только один такой параметр на метод.

```java
public void printNumbers(int... numbers) {
    for (int num : numbers) {
        System.out.println(num);
    }
}
printNumbers(1, 2, 3);
printNumbers();
```

Компилятор создаёт массив из переданных аргументов (синтаксический сахар).

## Q13. Можно ли получить доступ к переопределенному методу суперкласса? Можно ли получить доступ к переопределенному методу супер-суперкласса аналогичным образом?

Доступ к переопределённому методу непосредственного суперкласса — через `super.methodName()`. Доступ к методу супер-суперкласса напрямую (`super.super.methodName()`) в `Java` нельзя — синтаксис не поддерживается.

В подклассе можно вызвать только реализацию родителя одного уровня. Чтобы «дойти» до супер-суперкласса, родительский метод должен сам вызывать `super.methodName()` (цепочка вызовов).

```java
public class Animal {
    public void makeSound() { System.out.println("Animal"); }
}
public class Dog extends Animal {
    @Override
    public void makeSound() {
        super.makeSound(); // вызов Animal.makeSound()
        System.out.println("Dog barks");
    }
}
public class Puppy extends Dog {
    @Override
    public void makeSound() {
        super.makeSound(); // вызов Dog.makeSound(), тот уже вызывает Animal
        // super.super.makeSound(); // Ошибка компиляции
    }
}
```

## Q14. Что такое `Object` и какие методы по умолчанию у всех объектов?

`Object` — корневой класс всех классов в `Java`. Методы: `equals()`, `hashCode()`, `toString()`, `clone()`, `getClass()`, `notify()`, `notifyAll()`, `wait()`, `finalize()` (deprecated). При переопределении `equals()` обязательно переопределять `hashCode()` (контракт). `toString()` используется при конкатенации и логировании.

## Q15. В чём разница между == и equals()?

`==` — сравнение примитивов по значению; для ссылок — по адресу (один и тот же объект). `equals()` — логическое равенство объектов; по умолчанию в `Object` сравнивает ссылки (как `==`). Для `String`, `Integer` и др. `equals()` переопределён и сравнивает содержимое. При переопределении `equals()` соблюдать контракт: рефлексивность, симметричность, транзитивность, консистентность, `x.equals(null)` возвращает `false`.

## Q16. Что такое `hashCode()` и контракт с equals()?

`hashCode()` возвращает целочисленный хэш объекта; используется в `HashMap`, `HashSet`. Контракт: если `a.equals(b)`, то `a.hashCode() == b.hashCode()`; при `equals() == true` хэши должны совпадать. Обратное не обязательно. При переопределении `equals()` обязательно переопределять `hashCode()`, иначе нарушение контракта и некорректная работа в хэш-коллекциях.

Практическая ценность ответа обычно повышается, если дополнить определение операционным контекстом: как решение ведёт себя под нагрузкой, при сбоях и в процессе сопровождения. На интервью ожидают, что вы назовёте критерии выбора и способ валидации решения через метрики и проверяемый сценарий.

## Q17. Что такое clone() и как правильно клонировать объект?

`clone()` в `Object` — protected, создаёт копию объекта (shallow copy). Класс должен реализовать `Cloneable` (marker interface); иначе `CloneNotSupportedException`. Глубокое клонирование — вручную копировать вложенные объекты или сериализация/копирующий конструктор. В современном коде часто предпочитают фабричные методы или конструкторы копирования вместо clone().

## Q18. Что такое `package` и `import`?

`package` — пространство имён для классов; соответствует структуре каталогов. `import` — импорт класса или статического члена из другого пакета; `import static` — импорт статических полей/методов. Полное имя класса — `package.ClassName`. По умолчанию класс без package попадает в безымянный пакет; в production рекомендуется явный пакет.

## Q19. Что такое `visibility modifiers` (`public`, `private`, `protected`)?

## Q23. Что такое `shallow copy` и `deep copy`?

# Шаблоны для cheatsheet-writer

Готовые скелеты для копирования при создании новых файлов в `cheatsheets/`.
Используются, чтобы не тратить токены на пересборку frontmatter и базовой
структуры каждый раз.

## Файлы

- **`cheatsheet-skeleton.md`** — обычная шпаргалка (тип `reference`).
  Используется для большинства тем: технология, паттерн, инструмент.
- **`category-readme-skeleton.md`** — индексный README для папки-категории
  (тип `index`). Один на каталог.
- **`redirect-skeleton.md`** — короткая обложка, указывающая на основной файл
  по той же теме. Нужна когда консолидируешь несколько файлов в один и хочешь
  сохранить старые ссылки.

## Как использовать

1. Скопировать нужный файл в целевой путь:
   `cp .claude/skills/cheatsheet-writer/templates/cheatsheet-skeleton.md \
       cheatsheets/<category>/<topic>.md`
2. Заполнить плейсхолдеры `<...>` и `YYYY-MM-DD`.
3. Перечитать `cheatsheets/CHEATSHEETS_ARCHITECTURE_AND_RULES.md` если есть
   сомнения по структуре.

Шаблоны намеренно минимальные — сложная логика про языковые правила, MCQ-в-JSON,
форматы заголовков и пр. живёт в `SKILL.md` рядом.

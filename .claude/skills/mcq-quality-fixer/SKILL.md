# Работа с MCQ

Следуй `docs/mcq-quality/workflow.md` и используй `PROMPT_PLAN_INTERVIEW.md`
целиком. Передай LLM исходный production JSON одной темы, парный Markdown и все
замечания. При любом изменении, даже одного вопроса, заново сгенерируй весь
JSON одной LLM-задачей. Замени только назначенный JSON полным результатом.
Не склеивай диапазоны и не накапливай патчи. Не запускай редакционные скрипты.

`LLM_READY` означает полный проход модели без известных существенных замечаний,
а не независимый или исторический FINAL. При новом замечании добавь его к
промпту и снова перегенерируй весь файл. Не затрагивай тему другого автора.

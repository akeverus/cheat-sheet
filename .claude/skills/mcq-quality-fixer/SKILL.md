# Работа с MCQ

Используй шаблон поручения MCQ-чату из `docs/mcq-quality/workflow.md`.
Автор читает весь `PROMPT_PLAN_INTERVIEW.md` и оба указанных снимка.
За одну задачу модель генерирует весь JSON заново.
Координатор сохраняет полный результат как есть, без приёмки отдельных вопросов
и проверки JSON, вариантов или пояснений. Без патчей, склейки, отдельной вычитки,
валидаторов и скриптов проверки. Контракт Jackson сохраняет модель при
генерации. Стандартный JSON-сериализатор допустим при записи.

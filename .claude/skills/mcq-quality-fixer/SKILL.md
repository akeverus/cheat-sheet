# Работа с MCQ

Следуй `docs/mcq-quality/workflow.md`. Передай LLM `PROMPT_PLAN_INTERVIEW.md`
целиком, весь исходный JSON одной темы и весь парный Markdown. Не составляй
списки замечаний по вопросам. За одну задачу модель генерирует весь JSON заново.
Координатор сохраняет полный результат как есть, без приёмки отдельных вопросов
и проверки JSON, вариантов или пояснений. Без патчей, склейки, отдельной вычитки,
валидаторов и скриптов. Контракт Jackson сохраняет модель при генерации.
